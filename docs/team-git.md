# Git으로 함께 관리하기

비공개 저장소: https://github.com/anfyznvhs3-droid/qai-2026

## 처음 참여

소유자가 팀원의 GitHub 계정을 저장소에 초대한 뒤 각자 인증하고 실행한다.

```powershell
git clone https://github.com/anfyznvhs3-droid/qai-2026.git
cd qai-2026
git switch -c work/내이름-작업명
```

이 폴더를 Codex 또는 Cursor에서 열고 `AGENTS.md`, `docs/competition-blueprint.md`를 읽는다. Git 사용자 이름·이메일은 각자 설정한다. 계정 토큰을 문서에 기록하지 않는다.

## 매 작업

작업 전 main의 최신 변경을 받고, 개인 브랜치에서 담당 파일만 수정한다. 변경을 커밋하고 브랜치를 push한 뒤 PR을 만든다. 다른 팀원이 확인하고 main에 합친다. 충돌은 내용을 비교해 해결하며 강제 push로 덮어쓰지 않는다. 회의 중 board·decision-log는 한 명만 수정한다.

## 포함 범위

- 공통 지침·대회 스킬 5개·코드·선택표·청사진
- 가이드북 텍스트 50종·핵심 데이터 카드·출처/해시 목록
- 뿌리산업 배경 정리와 공식 원문 출처
- `tools/jari/`: 보드와 한 줄 설치의 소스. 실제 회의 내용·로그인 키는 제외

원본 데이터, PDF/PPT/HWP, 모델, 로컬 접속 키와 환경 파일, 개인 회의 원고는 기본 제외한다. 가이드북 추출 텍스트도 원 출처 권리를 유지하며 이 저장소를 공개하거나 재배포하기 전에 이용 조건을 확인한다. 비공개 저장소는 오픈소스 공개가 아니다.

## JARI와 개인 설치의 관계

호스트 한 명만 저장소 루트에서 `node tools/jari/server.js`로 서버를 실행한다. 기본 포트는 3040이며 기존 서버가 실행 중이면 새 서버를 동시에 띄우지 않는다. 새 checkout에서 시작하면 새 보드와 접속 키가 만들어지며, 기존 회의 데이터는 자동 이전되지 않는다.

현재 운영 서버는 `F:\working\002.USEFUL\qai-jari`에 유지한다. Git의 `tools/jari`는 관리용 소스이며 운영 폴더로 자동 배포되지 않는다. 이후 소스 변경은 Git에서 관리하고 운영 반영은 별도로 수행한다.

팀원은 호스트 보드의 설치 명령을 실행해 전역 `qai`를 설치할 수 있다. 이 설치가 만드는 `QAI-2026` 폴더와 Git clone 폴더는 별개다. `qai sync`는 회의 상태만 갱신하며 `git pull`을 대신하지 않는다. 현재 CLI는 설치 폴더를 대상으로 하므로 Git 작업 중 회의 자료는 설치 폴더의 `.qai/board.json`에서 참조한다. 두 폴더를 자동 병합하는 기능은 아직 없다.

## 현재 검증 범위

초기 업로드에서 제외 파일·비밀값 패턴·파일 규모를 확인한다. 학습·테스트·새 checkout의 서버 실행은 수행하지 않는다. 다른 노트북의 clone·설치·접속과 최종 재현은 팀원이 참여한 뒤 확인한다.
