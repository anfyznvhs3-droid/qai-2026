## 아이디어 → 문제 프레임 (VEDA·현장 근거 — 작성자는 안 읽어도 됨)

1. **손실 → 데이터 → 행동** 순서로 묻는다. 모델보다 「예측 후 누가 무엇을 바꾸나」가 재직자 평가(현장 적용성·실효성)의 핵심 — `AGENT.MD` §1 · 2025 정성 70점.
2. 문제를 **material / location / order / task** 중 어디에 붙는지로 보면 Join 키가 보인다 (LOT=material·order, 설비=location, 공정=task) — `ref-veda-mfg-fde-ontology`.
3. 「자동화 전에 프로세스를 다시 본다」 — 대응 방식(§2)이 애초에 잘못됐다면 예측이 아닌 재설계가 답일 수 있음 — `ref-veda-hammer-reengineering`.
4. 근본원인·EPS(CQI-20) 관점: 불량은 **조건 이탈**의 결과 — 예측 변수는 검사 결과가 아니라 **공정 조건** 쪽에서 찾는다 — `ref-veda-mfg-schema-core`.
5. 뿌리산업(주조·금형·소성·용접·표면·열처리)은 KAMP 50종의 절반 이상과 겹친다 — 현업 문제가 뿌리 6공정이면 후보가 많다 — `ref-veda-kpic-root-industry`.
6. KAMP 활용사례 65건은 「무엇이 이미 시도됐나」 확인용 — `ref-veda-kamp-usecases` · `knowledge/KAMP-absorption-report.md`.
