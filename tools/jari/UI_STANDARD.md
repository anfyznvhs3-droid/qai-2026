## 시각 기준

- 장식 테두리 없음. 여백과 배경 밝기로 영역을 구분한다. 키보드 초점 윤곽선은 유지한다.
- 배경 #F6F7F8, 표면 #FFFFFF, 본문 #202825, 보조 #64706A, 강조 #23654C.
- 제목 28px, 구역 제목 20px, 아이디어 핵심 17px, 본문 15px, 보조 12~14px.
- 간격 4 / 8 / 12 / 16 / 24 / 32px. 카드 모서리 8px, 입력 6px.
- 초록 강조는 현재 화면·내 선택에 사용한다. 후보는 옅은 초록 배경과 글자로 표시한다.
- 아이디어는 개인별 입력 폼 없이 01~10 취합 블록으로 보여준다. 빈 항목에는 ‘취합 대기’만 표시한다.
- 채팅과 팀 작업은 보조 영역이다. 처음에는 접는다.
- 내용·득표·검증 여부를 혼동하지 않는다. 취합 완료는 검증 완료가 아니다.
