    현장 × KAMP 2종 × VEDA

    현장A9의 변동점 공유·영향 제품 확인 지연. 변경 사건에서 영향 범위와 검증 결과까지 이어야 합니다.
    KAMP 후보원문 1 + 19는 동일 제품 조인 근거 미확인. 열처리로 재정의한 60 + 61은 배정번호·TAG_MIN 후보가 있으나, 원본 시점·중복·라벨을 확인해야 합니다. TAG_MIN은 수집 시각이지 제품 TAG가 아닙니다.
    AI 역할주 데이터의 공정 상태와 보조 데이터의 과거 이력을 예측 시점 이전에만 결합해 품질 위험을 추정. 주 데이터 단독과 융합 모델을 같은 분할에서 비교하고 확률을 보정합니다.
    VEDA 역할관리계획의 반응 계획, 추적성의 영향 범위, PFMEA의 실패 영향, Lean의 대기·불량 손실을 현장 질문으로 변환합니다. VEDA 본문은 모델 학습 입력이 아닙니다.

    현재 가이드북만으로 변경 사건 로그, 초품 결과, 제품 TAG, 정상 복귀 승인 기록의 존재는 확인되지 않았습니다. 이 항목은 현장 확인 전에는 비워 둡니다.

    연관 신호 가중치

    문자 n-gram TF-IDF 벡터 + 규칙 기반 신호. 값을 바꾸면 탐색 순위가 즉시 바뀝니다.

    각 신호를 0~1로 계산하고 가중 평균합니다. 표시 가중치는 50개 후보에 소프트맥스를 적용한 상대 분포입니다. 이 계산은 학습된 Attention 모델, 적합 확률, 성능 예측이 아닙니다.
