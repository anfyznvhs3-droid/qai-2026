## 요지

| 개념 | 내용 |
| --- | --- |
| **Matthew Effect** | LLM RL은 **쉬운 문제**에 compute·성능이 쏠림 — 어려운 문제는 거의 안 늘음 («the rich get richer») |
| **NGU** | 프롬프트당 k샘플 후 **풀리면 빠르게 필터** · **안 풀리면 p_NGU 확률로 재샘플** (never give up) |
| **효과** | async RL에서 **compute를 어려운 케이스로 재배치** — Deepscaler·Manufactoria에서 hard subset 개선 |
| **vs GRPO** | 고정 k는 easy에 낭비 또는 hard에 k↑로 전체 비용 폭증 — NGU는 **적응적 k** |
