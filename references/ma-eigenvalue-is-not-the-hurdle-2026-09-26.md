## 트윗 vs README

| 트윗 | README |
| --- | --- |
| 신호 자산, 매매 자산, 이동평균 길이를 여러 개 넣는 명령줄 프로그램이고 파이썬인데 빠르다 | 일간 가격과 이동평균 교차만 다룬다. 필요한 평균을 한 번 계산하고 NumPy로 격자를 전부 평가한다. 실행 시간 수는 없다 |
| 여러 시스템을 시험하면 최고 샤프와, 유효 시스템 수로 깎은 샤프를 같이 보고한다 | `--deflate`는 유효 시행 수를 여러 개 내고 Deflated Sharpe를 보고한다. 정의가 하나뿐인 척하지 말라고 적는다. 표준 DSR 허들이 쓰는 수는 평균 상관의 EffN-B다 |
| 길이 2부터 200까지면 199개보다 유효 수가 훨씬 작다. 평균 상관이나 고유값 스펙트럼으로 추정한다. 고유값이 훨씬 작아서 놀랐고 더 현실적이다 | 예시 격자는 `1:50`과 `2:200`이라 50×199=9,950칸이다. 199는 그 격자의 한 변이다. EffN-G는 Galwey의 고유값 개수다. 고유값이 더 현실적이라는 문장은 없다 |
| 2003년 이후 SPY 수익은 IEF가 20일 같은 단기 이동평균 위에 있을 때 평균이 더 높다 | `IEF 20 200 --trade SPY` 명령은 있다. 2003년과 그 평균 비교는 없다 |
