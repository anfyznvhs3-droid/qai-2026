## 게시 요약

논문·보고서 작성 시 참고문헌을 `.bib`(BibTeX/BibLaTeX)로 관리하는 오픈소스 도구.

- arXiv, PubMed, Google Scholar 등 **앱 내 검색**
- DOI·ISBN·PubMed-ID·arXiv-ID로 서지정보 **자동 수집**
- PDF **메타데이터 추출**, 브라우저 **확장**으로 원클릭 import
- Word/LibreOffice **인용 삽입**, 인용 **스타일 전환**
- 15종 이상 import, **중복 병합**, 읽음·우선순위 태그
- `.bib` = **순수 텍스트** → git / 공유 / 협업
