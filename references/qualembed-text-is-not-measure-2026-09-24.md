OSF 양식은 「데이터 수집·분석 없음」으로 체크되어 있다. PDF는 Big Five, PANAS, Schwartz 가치, Pineo-Porter 직업 위신, ISEAR·Kjell 서사를 공개 데이터로 재검증한다. 근거는 PDF다.

## 트윗 vs PDF

| 트윗 | PDF |
| --- | --- |
| 질적 텍스트의 의미를 LLM으로 잰다 | 좌표의 코사인은 유사도. **의미 판단은 분석가에게 남는다**고 초록이 못 박음 |
| 소쉬르에서 추적 | §계보에 소쉬르의 valeur(값은 대비에서 온다)가 있음. 트윗과 맞음 |
| 오픈 데이터로 검증 | 맞음. 다만 결과의 핵심은 **실패에 가깝다** |
| 클라이언트 데이터 윤리 | §3.7 「Data Ethics for Participant Text」 규칙 6개 |
| R 라이브러리 | `qualembed`. 분석은 R 4.5.0. 임베딩은 API로 보냄 |

초록의 검증 문장: 언어 구조만으로는 심리측정 구조가 재현되지 않았다. 문항 문장은 일부를 되돌리고, **관계에 부호가 있으면 아무것도 되돌리지 못한다.** 응답을 반으로 가른 신뢰도 천장에는 한참 못 미친다. 척도의 문장은 응답자가 준 것을 담고 있지 않다.

## Q.AI 판단

| 옵션 | 판정 | 이유 |
| --- | --- | --- |
| `qualembed` · Gemini·Voyage 등 임베딩 API | ❌ | 외부 API. 제출은 GBDT. 불량명·알람 문장을 벡터 피처로 만들지 않음 |
| 코사인으로 「의미가 가깝다」를 KPI·피처에 | ❌ | 논문이 부호 있는 관계를 코사인이 못 담는다고 함. 손실의 크고 작음은 현장 KPI |
| 범주 이름(불량 코드, 설비명)을 임베딩 | ❌ | 더미는 「다르다」만 말한다. 문장 좌표도 공정 측정이 아니다. 코드는 가이드북 범주로 두거나 뺀다 |
| **패턴** — 임베딩은 익명 파생 파일이 아님 | ✅ | §3.7. 벡터에서 원문이 되살아날 수 있어, 참여자 텍스트와 같은 의무를 진다. 현장 메모·아이디어 폼 문장은 API로 보내지 않는다 |
| 공개 KAMP 표를 「공개라서 임베딩해도 된다」 | ❌ | 논문은 공개 척도에 한해 API 전송이 문제없다고 적는다. 우리 모델 정책은 그 앞에서 이미 API를 끈다 |

`gem-dualsql`은 지표가 학습 목표를 오염시키는 문제. `gem-kronos`는 다른 도메인 가중치. 본 건은 **문장 유사도는 부호 있는 양을 대체하지 못한다**만 담당한다.

## 윤리 6규칙 (재현 절차 없음)

분석 동의가 전송 동의는 아니다. 무료 티어는 공개 문장만. 이름 삭제는 서사를 익명으로 만들지 못한다. 임베딩 행렬은 원문과 같이 다룬다. 동의가 없으면 로컬만. 래퍼 캐시가 평문 사본을 디스크에 남긴다.

임상 노트 복원 공격의 방법·수치는 PDF에 인용만 되어 있다. 여기에 적지 않는다. 팀 규칙으로 필요한 것은 「보내지 않는다」까지다.
