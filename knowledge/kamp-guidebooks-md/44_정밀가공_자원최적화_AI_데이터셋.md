1. 분석 개요
1.1 분석 배경
1) 공정(설비) 개요
• 레이저 미세 홀 가공
- 레이저를 이용한 미세 홀 가공은 홀의 크기(지름)에 따라 매크로(macro) 가공기술
(100μm 이상)과 마이크로(micro) 가공기술(50~0.1μm)로 구분할 수 있으며, 홀 형
상은 원형, 타원형, 사각형 등 용도에 따라 다양하다.
- 매크로 가공기술은 철강, 자동차, 선박, 항공기 산업 등 중공업 분야에, 마이크로 가공
기술은 전기, 전자, 반도체 산업에 주로 활용되고 있다.
- 대상 공정은 MLCC(Multi Layer Ceramic Capacitors) 및 반도체 제작에 사용되는
적층용 Vacuum Plate 가공공정으로, 레이저 가공기를 이용해 지름 0.5mm 미만 홀
을 최대 25,000개 이상 뚫는 초정밀 금속 가공 공정이다.

2) 이슈사항(Pain point)
• 공정(설비)상의 문제 현황
- 현재, 해당 공정은 1차 홀 가공 후, 품질검사 단계를 거쳐 불량 발생 시 2차 홀 재가공
을 진행하고 있다.
- 홀 가공 및 품질 검사과정에서 여러 가지 형태의 불량이 검출되는 경우가 있으며, 수
mm 지름, 수만 개 홀을 사람이 직접 전수조사해서 불량을 정확히 찾아내는 것은 현
실적으로 불가능하다.
- 레이저 가공 후, 전수검사를 통해서 불량 홀을 찾아야 하는 현재의 공정으로 인해 검
사 및 불량수정에 따른 인력, 시간, 비용 등 자원이 과다 소요되는 어려움이 있다.
- 따라서, 1차 홀 가공 중, 정상 홀과 불량 홀을 정량적으로 검출할 수 있는 AI 기술을
도입해, 현 공정을 개선하고 관련 자원을 최적화할 필요가 있다.
• 문제해결 장애요인
- 정상 홀과 불량 홀 식별에 사용할 수 있는 정량적인 데이터가 확보되어 있지 않아 분
석에 어려움이 있다.
- 불량 홀은 여러 요인으로 발생할 수 있으며, 상대적으로 성능이 우수한 지도학습
(supervised learning) 알고리즘을 적용하기 어렵다.
• 극복 방안
- 레이저 홀 가공 과정에서 발생하는 불량을 감지하기 위한 정상 홀 가공과 불량 홀 가
공에 대한 데이터 확보를 위해, 시편을 제작하고 관련 데이터를 취득한다.
- 현 사용 중인 레이저 가공기로부터 이와 관련된 설비, 공정 파라미터를 직접 추출할
수 없어, 적절한 센서를 이용해 간접적으로 관련 데이터를 취득할 필요가 있다.
- 따라서, 포토다이오드 센서를 이용해 홀 가공 시 발생하는 레이저의 반사광(light)에
대한 빛의 세기(intensity) 데이터를 비지도 학습(unsupervised learning) 알고리즘
에 적용한다.
- 1차 가공된 홀의 정량적인 품질검사가 이루어질 경우, 2차 홀 재가공과 관련된 현행
공정을 개선할 수 있고, 이를 통한 자원 최적화를 기대할 수 있다.

1) 분석 목표
- 레이저를 이용해 가공된 미세 홀을 정상 홀과 불량 홀로 구별하는 AI 분석모델을 개발

3) 데이터 분석 기대효과
- 1차 홀 가공 후, 홀 품질검사 자동화로 2차 홀 가공을 개선함으로써, 관련 인력, 시간,
비용 등 자원을 줄일 수 있다.
- 또한, 제품생산 중간 과정에서 홀 불량 여부를 미리 판별하기 때문에 과다한 불량 홀의 경
우 이후 공정 진행을 사전에 차단함으로써, 원가절감 및 생산성 향상을 기대할 수 있다.
- 결과적으로, 자동화된 품질검사 방법으로 최종 제품의 품질개선 및 불량률 감소를 기대
할 수 있다.
4) 시사점(implication)
- 가공 홀 품질 수준은 현재 작업자들이 직접 육안을 통해 확인하고 있으나, 미세한 홀 작
업 수준을 정확히 확인하기 어렵고, 주관적 판단이 개입될 수 있다.
- 이러한 문제를 해결하기 위해, 포토다이오드 센서를 이용해 레이저 홀 가공 중에 발생
하는 레이저 반사광 데이터를 정상 홀과 불량 홀에 대해 각각 수집했다.
- 수집된 정상 홀 데이터를 비지도 학습기반 LSTM Autoencoder 모델로 학습하고, 복
원 오차(reconstruction error)를 이용해 정상 홀과 불량 홀을 구별할 수 있다.
- 1차 홀 가공에 AI 분석모델을 적용해, 2차 홀 재가공 관련 공정을 생략할 수 있으며, 이
에 따른 자원 소모를 줄일 수 있다.

3) 데이터(품질) 전처리
• 데이터 품질 전처리 목적
- 실제 공정에서 발생하는 데이터들은 값이 의미 없거나 누락 및 오타가 발생하여 데이
터 품질이 떨어진다.
- 아무리 좋은 분석 방법론을 가지고 있더라도 품질이 낮은 데이터를 이용하면 좋은 결
과를 얻을 수 없으므로, 데이터 품질 전처리는 데이터 분석에서 가장 중요한 단계이다.
- 따라서, 데이터들의 6가지 품질지수를 파악하고, 데이터 전처리를 통해 품질지수를
향상한다.
• 데이터 품질 지수
- 완전성(Completeness) : 필수항목에 누락이 없어야 한다.
- 유일성(Uniqueness) : 데이터 항목은 유일해야 하며 중복돼서는 안 된다.
- 유효성(Validity) : 데이터 항목은 정해진 데이터 유효범위 및 도메인을 충족해야 한다.
- 일관성(Consistency) : 데이터가 지켜야 할 구조, 값, 표현되는 형태가 일관되게 정의
되고, 서로 일치해야 한다.
- 정확성(Accuracy) : 실제 존재하는 객체의 표현 값이 정확히 반영되어야 한다.
- 무결성(Integrity) : 데이터베이스 자료의 오류 없이 변화에 영향을 받지 않고 데이터
의 유일성, 유효성, 일관성이 보호돼야 한다.
• 데이터 품질 지수 세부 설명
완전성 품질지수 = (1 - (결측치 데이터 수 / 전체 데이터 수)) × 100
- DataFrame 객체에서 사용할 수 있는 isna() 함수를 이용해 결측치 데이터 수를 구하
고, len() 함수를 이용해 전체 데이터 수를 구한 후 완전성 품질지수를 측정한다.
유일성 품질지수 = (유일한 데이터 수 / 전체 데이터 수) × 100
- DataFrame 객체에서 사용할 수 있는 unique() 함수를 이용해 유일한 데이터 수를
구하고, 유일성 품질지수를 측정한다.
유효성 품질지수 = (유효성 만족 데이터 수 / 전체 데이터 수) × 100
- 데이터 취득에 사용된 포토다이오드 센서는 초당 8개(8Hz) 검출 값을 수집하기 때문
에, 전체 데이터에 대해 1초 내 8개 검출 값이 존재하는지를 확인해 유효성 만족 데이
터 수를 구하고 유효성 품질지수를 측정한다.

<!-- p.12 -->
11
일관성 품질지수 = (일관성 만족 데이터 수 / 전체 데이터 수) × 100
- ‘Time’, ‘Intensity’, ‘Current’의 각 데이터 타입이 정확히 반영되었는지, 전체 데이터
에 대해 조사해 일관성 만족 데이터 수를 구하고 일관성 품질지수를 측정한다.
정확성 품질지수 = (1 - (정확성 위배 데이터 수 / 전체 데이터 수)) × 100
- 분석에 사용된 데이터 시계열 데이터로 시간순으로 수집된 레이저 가공기의 반사광
데이터를 이용하므로, 이에 대해 전체 데이터를 대상으로 정확성 위배 데이터 수를 구
하고 정확성 품질지수를 측정한다.
무결성 품질지수 = (유일성, 유효성, 일관성 지수중 100%가 되는 지수 개수 / 3) × 100
- 계산된 유일성, 유효성, 일관성 품질지수를 이용해 무결성 품질지수를 측정한다.
가중치 지수 = 품질지수 × 가중치
- 안전성, 유일성, 유효성, 일관성 정확성, 무결성 품질지수에 각 0.2, 0.2, 0.2, 0.15,
0.15, 0.1의 가중치를 부여하고 가중치 지수를 계산한다.
데이터 품질지수 = Σ 가중치 지수
- 가중치를 각 품질지수에 적용해 종합적인 데이터 품질지수를 측정한다.

은 현실적으로 많은 어려움이 따른다.

- 또한, 실제 현장에서 불량 홀 발생빈도가 정상 홀 발생빈도에 비해 현저히 낮으므로,
AI 학습을 위한 충분한 양의 불량 홀 데이터 확보에 많은 기간이 소요된다.
- 따라서, 상대적으로 쉽게 데이터 취득이 가능한 정상 홀 데이터를 이용해 비지도 학습
모델을 구현하고, 이를 이용해 불량 홀을 식별하는 것이 현실적인 접근방법이다.
- 본 실습에서 사용하는 데이터는 레이저 가공기가 홀을 가공하는 동안 계속해서 수집
되는 시계열(timeseries) 데이터로, 이러한 데이터 특성을 잘 반영할 수 있는 AI 모델
이 필요하다.
- 많은 수의 정상 홀 데이터로부터 유사한 패턴을 학습하고, 예상을 벗어난 불량 홀 패
턴을 식별하는 문제는 이상 탐지(anomaly detection) 문제로 분류된다.
- 결과적으로, 비지도 학습방식, 시계열 데이터 분석, 이상 탐지 성능 등을 고려해 분석
모델로 LSTM Autoencoder를 선정했다.
• 적용하고자하는 AI 분석 방법론(알고리즘)의 구체적 소개
- Autoencoder는 비지도 학습의 가장 기본적인 형태로, 입력 데이터(input data)를
보다 작은 차원의 데이터로 압축하는 인코더(encoder)와 압축된 데이터에서 다시 원
래 차원으로 복원하는 디코더(decoder)로 구성된다.
- 즉, 입력 데이터를 최대한 복원한 출력 데이터를 학습하는 딥러닝 모델이다.
- 이때, 입력 데이터를 원본 데이터, 출력 데이터를 복원 데이터라고도 하며, 원본 데이
터와 복원 데이터 사이에 발생한 차이를 복원 오차라고 한다.
- 복원 오차는 일반적으로 학습 때 등장하지 않았던 새로운 패턴의 데이터에 대해 상대
적으로 크게 나타나기 때문에, 이러한 Autoencoder 모델의 특성을 이용해 불량 홀
탐지와 같은 이상 탐지 문제에 효과적으로 적용할 수 있다.
[그림 8] LSTM Autoencoder 모델

<!-- p.14 -->
13
- LSTM Autoencoder는 인코더, 디코더에 시계열 데이터 학습에 주로 사용되는 LSTM
구조를 활용한 모델로 입력(원본) 시퀀스(sequence)를 인코더와 디코더를 거쳐 최대
한 입력 시퀀스와 유사한 출력(복원) 시퀀스 생성을 학습하는 모델이다.
- 입력 시퀀스와 출력 시퀀스의 차이(복원 오차)를 계산하는 방법으로 평균 절대 오차
(MAE, Mean Absolute Error)를 이용한다.
- MAE는 입력 시퀀스와 출력 시퀀스의 절댓값 차이의 평균값으로 다음과 같이 정의된다.
- MAE는 학습에 사용된 시퀀스와 유사한 패턴의 경우 작은 값을 갖고, 패턴이 상이할
수록 큰 값을 갖는다.
- 따라서, 정상 홀 데이터를 학습한 LSTM Autoencoder 모델에 불량 홀 데이터(시퀀
스)가 입력되는 경우 큰 MAE 값을 갖게 되어 정상 홀과 불량 홀을 효과적으로 구분
(분류, 식별)할 수 있다.
- 이때, 정상 홀과 불량 홀을 구분하는 MAE 값을 임계치(threshold)라고 한다.
- 본 실습에서는 3 시그마 규칙(three sigma rule)을 적용해 학습 데이터 MAE 분포 값
의 3 표준편차 범위(99.7%) 값을 임계치로 이용하며, 임계치보다 작은 MAE 갖는 시
퀀스는 정상 홀로, 임계치보다 큰 MAE를 갖는 시퀀스는 불량 홀로 구분한다.
• AI 분석 방법론(알고리즘) 구축 절차
- 레이저 가공기를 이용해 미세 홀을 가공할 때 발생하는 레이저 반사광 데이터를 이용해
정상 홀과 불량 홀을 구분하는 것을 목표로 하며, 다음 절차에 따라 분석을 수행한다.
① 패키지/데이터 불러오기 : 분석에 필요한 파이썬 패키지를 선언하고, 제공된 데이터셋의 내용
을 표 형식과 그래프 형식으로 확인한다.
② 데이터 탐색 : 데이터의 구성, 통계치를 확인하고 상관분석을 수행한다.
③ 데이터 전처리 : 데이터셋을 학습용과 평가용으로 분리하고, AI 모델 적용을 위해 데이터 표준
화, 데이터 형태 변환을 수행한다.
④ AI 모델 구축 : 순차 모델(sequential model) 방식으로 LSTM Autoencoder 모델을 작성한다.
⑤ AI 모델 학습 : 학습 데이터셋을 이용해 모델을 학습하고, 학습 결과를 확인한다.
⑥ 임계치 설정 : 학습 데이터셋의 복원 오차를 확인하고, 3 시그마 규칙(three sigma rule)을 적
용해 임계치(threshold)를 결정한다.
⑦ AI 모델 평가 : 임계치를 이용해 평가 데이터셋의 데이터를 평가(정상 홀, 불량 홀 구분)하고,
혼동 행렬(confusion matrix)을 이용해 모델의 정확도(accuracy)를 확인한다.
⑧ 결과분석 : 분석 결과를 토대로 활용방안을 설명한다.

름>’ 형식으로 선언한다.
- 패키지에 포함된 모든 모듈(객체, 함수)을 이용하고자 하는 경우 ‘import <패키지 이

②-3. 상관분석
- DataFrame에 corr() 함수를 호출해 각 컬럼 사이의 상관분석을 할 수 있다.
- 상관분석은 두 변수가 어떤 선형적 관계를 갖는지 분석하는 방법으로, 이때, 두 변수
는 서로 독립적인 관계이거나 상관된 관계일 수 있다.
- 두 변수 관계의 강도를 상관관계라고 하고 상관계수로 그 정도를 파악할 수 있다.
- corr() 함수를 호출해 ­1 에서 1 사이의 상관계수를 확인할 수 있으며, 이때, 상관계수
는 1과 가까운 값일수록 강한 양의 상관관계(비례)를, ­1과 가까울수록 강한 음의 상관
관계(반비례)를 나타낸다.
- 상관관계 정도는 결괏값의 절댓값이 0.1~0.3이면 약한 선형관계, 0.3~0.7이면 뚜렷
한 선형관계, 0.7 이상은 강한 선형관계를 갖는 것으로 판단한다.
- [코드 15]와 같이, 정상 홀 데이터셋(normal_dataset)의 상관분석 결과 ‘Intensity’와

print('정확성 품질지수: %d%%' % accuracy)
