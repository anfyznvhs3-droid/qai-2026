알고리즘
간략소개
MTadGAN 알고리즘은 다변량 시계열에 대한 이상 탐지를 위해 적대적 생성자 네트워크(GAN)를 적용
하고 효율적인 학습을 위해 Wasserstein 손실함수를 적용하는 알고리즘이다. 시계열 입력 데이터의 공
간 X에서 잠재 공간 Z로 보내는 부호화 생성자 E와 역으로 잠재공간에서 가짜 샘플을 만드는 생성자 G
를 네트워크로 구성하고 이들 사이에 두 개의 적대적인 판별자 네트워크를 도입하여 최대한 가짜와 실
제 데이터를 구별할 수 있도록 하고 더하여 순환-일관성이 있도록 학습하며 이를 이용해서 구한 이상 점
수를 기반으로 이상 신호를 탐지하는 알고리즘이다.

2) 이슈사항(Pain point)
● 공정(설비)상의 문제 현황
- 배터리팩 충·방전 시험은 자동화 설비가 없이 수작업으로 진행되고 있으며, 작업자 역
량에 의존하고 있어 작업관리 및 품질관리에 어려움이 있다. 특히, 배터리팩은 다수의
배터리모듈과 배터리모듈을 구성하는 배터리셀들의 집합체이기 때문에 충·방전 시험
중 불량이 발생하면 불량원인을 분석하고 불량품을 교체하는 과정을 거쳐야 한다. 그
러나 불량원인을 분석하는 과정에서 경계성 판단이 필요한 경우가 발생하기 때문에
숙련된 핵심 기술자의 역량에서 대처 가능한 상황이다.
● 불량현상 및 원인
- 용량불량: 배터리팩은 수많은 배터리 모듈과 배터리셀들로 구성되기 때문에 테스트
과정에서 불량 배터리셀이 발견되면 모듈 단위로 교체를 해야 하는 경우가 많다. 용량
불량의 경우 충·방전 시험 과정에서 특정 배터리셀에서 급격하게 전압이 상승/하강하
는 구간이 발견된다는 특징을 가진다. 충전의 경우 초기에 비슷하게 출발하나 충전이
완료된 후 비교해 보면 그 차이가 뚜렷하다. 아래 그림에서 붉은색과 녹색의 베터리
셀이 이 경우에 해당하지만 배터리모듈 마다 평균 전압 차이도 고려해야 하기 때문에
불량을 판정하는 기준에 경계성 판단이 요구되므로 전문가 검토가 필수적이다.

- 배터리팩 충·방전 시험 설비공정을 통해 수집한 데이터를 기반으로 제품의 품질을 예측
하여 품질관리를 강화하고 불량의 발생 원인을 분석하여 생산성을 높일 수 있다. 또한,
본 분석에서는 AAS 표준기반 제조데이터 수집/저장 체계를 적용하여 납품된 배터리팩
의 라이프사이클 관리에도 활용될 수 있으므로 지속관리가 필요한 현장에서 본 분석이
폭넓게 활용될 수 있을 것으로 기대된다.

4) 시사점(implication) 요약기술
- 현재 배터리팩은 충·방전 시험 설비를 통해 측정한 데이터를 기준으로 양품과 불량품이
선별되고 있지만, 대부분은 작업자의 노하우에 의존하여 선별이 진행되고 있어 품질을
보장하기 어려운 상황이다.
- 실제 불량 사례가 있음에도 불구하고 문제가 발생한 시점과 원인을 정확하게 파악하기
어려워 생산 지연으로 이어지는 경우가 빈번하게 나타나고 있다.
- 본 분석에서는 배터리팩 충·방전 시험 설비로부터 매초마다 수집되는 공정 데이터를 기
반으로 AI 모델을 생성하여 시스템 상에서 제품의 품질예측과 불량이 발생한 원인을
자동으로 판단할 수 있도록 지원한다.
- 또한, AAS 표준기반 제조데이터 수집/저장 체계를 통해 향후 납품된 배터리팩의 라이
프사이클 관리에도 활용될 수 있으므로 생산 제품의 품질 향상과 함께 지속관리가 필요
한 현장에 본 분석이 활용될 수 있다는 점에서 시사점이 크다고 판단된다.

3) 데이터 품질 전처리
● 데이터 품질 전처리 목적
- 원시 데이터 (raw data)의 수집은 다양한 센서를 사용하여 배터리의 수명과 관련이
있는 데이터를 수집하여 저장함으로써 이루어진다.
- 실제 현장의 데이터는 의미 없는 값을 포함하거나 결측치, 혹은 이상 데이터가 발생하
여 데이터 품질이 떨어진다.
- 품질이 낮은 데이터를 이용하면 좋은 결과를 얻을 수 없으므로 데이터의 전처리
(data pre-processing) 단계를 수행한다.
- 데이터의 품질을 측정하는 기준으로 다음 6가지 항목에 대하여 측정하여 데이터 품질
지수를 산출하고, 데이터의 전처리를 통하여 품질을 개선한다.
항목
항목 설명
완전성
(Completeness)
데이터의 필수 항목에 결측치가 없어야 함을 의미한다.
유일성
(Uniqueness)
데이터 엔티티 (data entity)가 관련 애플리케이션 내에서 고유하게 캡처, 표시 및 참조되어야 함을
나타낸다. 즉, 논리적으로 중복되는 엔티티가 없으며 데이터 세트 내의 각 엔티티를 고유하게 액세
스하는 데 사용할 수 있는 고유 식별자가 있어야 함을 의미한다.
유효성
(Validity)
데이터 항목은 정해진 데이터의 유효범위 안에 있어야 한다.
일관성
(Consistency)
데이터의 구조, 유형 및 값은 형태가 일관되게 정의되고, 서로 일치해야 한다. 즉, 동일한 데이터 엔
티티에 대하여 한 데이터셋의 데이터 값이 다른 데이터 세트의 값과 일관성이 있어야 함을 의미한다.
정확성
(Accuracy)
데이터가 모델링하려는 실제 개체를 정확하게 표현하는 정도를 나타낸다. 즉, 데이터 항목이 검증
된 정확한 정보 (예: 참조 데이터)와 얼마나 일치하는지에 따라 측정된다. 정확성을 검증하기 위해
서는 확증을 위한 참조 데이터 (다른 테이블의 유사한 확증 데이터 값)나 상관성이 존재하는 기존
의 테이블의 값과 비교한다.
무결성 (Integrity)
데이터베이스 자료의 오류 없이 변화에 영향을 받지 않고 데이터의 유일성, 유효성, 일관성이 보호
되어야 함을 의미한다.

- 알고리즘 선정 이유: 배터리 충·방전 데이터는 약 170개 이상의 셀들의 전압과 온도
등으로 이루어져 있는데 이들 전압과 온도 값은 시간에 대해 서로 비슷한 함수로서
서로 간에 높은 상관관계를 가지고 있다. 이러한 다변량 시계열 데이터를 효율적으로
다루기 위해서는 차원을 낮추는 PCA 알고리즘이 유용하다. 또한 이러한 데이터에서
의 이상(anomaly)은 흔히 전압값 등의 갑작스런 변화로 나타나는바 이러한 이상의
탐지에는 MTadGAN 같은  적대적 생성 모형이 효율적인 것으로 판단되어 이를 선정
하였다.
(1) 주성분분석(PCA, Principal Component Analysis) 알고리즘은 많은 성분을 가지는 데이터
의 차원을 낮추는 알고리즘으로  데이터의 분포를 계산하여 고차원에서 저차원으로 독립 변수
의 개수를 낮추고 다음 단계의 AI 계산의 입력으로 하여 이상 탐지, 분류 등에 사용할 수 있도
록 하는 알고리즘이다.
(2) MTadGAN(Multivariate Time Series Anomaly Detection by Generative Adversarial
Network)은 다변량 시계열에 대하여 적대적 생성망의 방법을 적용하여 이상 탐지를 수행하
는 알고리즘이다.
(3) 시계열 데이터에서의 이상(anomaly)이란 어떤 시계열 데이터 상에서 우리가 일반적으로 자
연스럽게 일어나리라고 예측하는 패턴과 너무도 다른 패턴을 보이는 특정한 점이나 구간을 가
리킨다. 여기에서 묵시적인 가정은 주어진 데이터가 어떤 특정한 규칙이나 법칙에 따라 생성

된다고 보는 것이다. 따라서 이상을 나타내는 점이나 구간은 데이터의 생성 규칙이나 법칙에
의해 생겨났다고 믿기 어려운 것을 의미한다. 따라서 이상 탐지(anomaly detection)는 흔히
주어진 데이터를 잘 기술하는 모형(Model)을 먼저 구성하고 이로부터 각각의 데이터 점들 중

① 이상값 데이터는 정상 데이터에 비해 매우 적게 발생하고 많은 분야 에서 이상 상태 데이

사용된다.
② 시계열 데이터에서의 이상 탐지는 입력 데이터의 특성에 따라서 한 가지 측정량을 다
룰 경우 즉, 단변량(univariate) 데이터일 경우와 여러 가지 측정량을 동시에 다룰 경
우 즉, 다변량(multivariate) 데이터의 경우로 나누어 볼 수 있고, 데이터 값이 연속적
(continuous)인 변수 값일 경우와, 이와 달리 유한한 개수의 이산적(discrete)인 변수 값
을 가지는 즉, 범주적(categorical)인 경우로 나누어 볼 수 있다. 여기서는  다변량 데이터
에서의 이상 탐지를 위주로 다룬다. 이상 탐지의 출력의 관점에서는 개별 시점에 이상 여
부를 부여하는 경우, 즉 점 이상(point anomaly)과, 연속적인 구간에 이상 여부를 부여하
는 경우, 즉 구간 이상(subsequence anomaly)으로 나눌 수 있다.
(4) 적대적 생성 신경망(Generative Adversarial Networks, GAN)(Goodfellow, et al 2014)
을 이용한 시계열 데이터의 이상 탐지에서 적대적 생성 신경망은 이미지 생성, 이미지 변환,
그리고 비디오 예측 등에 성공적으로 활용되어 왔고 최근에는 이미지에서의 이상 탐지에서
도 그 효율성을 보였다. 하지만 시계열 데이터에 대한 GAN방식의 연구는 매우 드물었다. 이
는 시계열 데이터에 복잡한 시간적인 상관성(correlation)이 있어서 이에 생성적 모델을 적용
하기가 어렵기 때문이다. 최근에 Li, et al 은 시계열 데이터에 기본적인 GAN방식을 적용하

# Function for identify outlier
# Input parameter: the dataframe and constant for IQR boundary
# (make sure all of the column in dataframe is numerical data types)
# Output: all of rows identified as outliers
def identify_outliers(df, c):
    #set the constant for IQR boundary
    constant = float(c)
    # calculate Q1 and Q3
    Q1 = df.quantile(0.25)
    Q3 = df.quantile(0.75)
    # calculate the IQR
    IQR = Q3 - Q1
    # filter the dataset with the IQR
    IQR_outliers = df[((df.lt(Q1 - constant * IQR)) | (df.gt(Q3 + constant * IQR))).any(axis=1)]
    IQR_outliers = pd.DataFrame(IQR_outliers)
    return IQR_outliers

#
def diff_smooth_df(df, lags_n, diffs_n, smooth_n, diffs_abs=False, abs_features=False):
    “””Given a pandas dataframe preprocess it to take differences, add smoothing, and lags as specified.
    “””
    if diffs_n >=1:
        # take differences
        df = df.diff(diffs_n).dropna()
        # abs diffs if defined
        if diffs_abs ==True:
            df = abs(df)
    if smooth_n >=2:
        # apply a rolling average to smooth out the data a bit
        df = df.rolling(smooth_n).mean().dropna()
    if lags_n >=1:
        # for each dimension add a new columns for each of lags_n lags of the differenced and smoothed values for that dimension
        df_columns_new = [f’{col}_lag{n}’for n in range(lags_n+1) for col in df.columns]
        df = pd.concat([df.shift(n) for n in range(lags_n+1)], axis =1).dropna()
        df.columns = df_columns_new
    # sort columns to have lagged values next to each other for clarity when looking at the feature vectors
    df = df.reindex(sorted(df.columns), axis =1)
    # abs all features if specified
    if abs_features ==True:
        df = abs(df)
    return df

def time_segments_aggregate(X, interval, time_column, method=['mean']):
    """Aggregate values over given time span.
    Args:
        X (ndarray or pandas.DataFrame): N-dimensional sequence of values.
        interval (int): Integer denoting time span to compute aggregation of.
        time_column (int):  Column of X that contains time values.
        method (str or list):
          Optional. String describing aggregation method or list of strings describing
           multiple aggregation methods. If not given, `mean` is used.
    Returns:
        ndarray, ndarray:
            * Sequence of aggregated values, one column for each aggregation method.
            * Sequence of index values (first index of each aggregated segment).
    """
    if isinstance(X, np.ndarray):
        X = pd.DataFrame(X)
    X = X.sort_values(time_column).set_index(time_column)
    if isinstance(method, str):
        method = [method]
    start_ts = X.index.values[0]
    max_ts = X.index.values[-1]
    values = list()
    index = list()
    while start_ts <= max_ts:
        end_ts = start_ts + interval
        subset = X.loc[start_ts:end_ts-1]
        aggregated = [
            getattr(subset, agg)(skipna=True).values
            for agg in method
        ]
        values.append(np.concatenate(aggregated))
        index.append(start_ts)
        start_ts = end_ts
    return np.asarray(values), np.asarray(index)

def rolling_window_sequences(X, index, window_size, target_size, step_size,
                   target_column, drop=None, drop_windows=False):
    """Create rolling window sequences out of time series data.
    The function creates an array of input sequences and an array of target sequences
    by rolling over the input sequence with a specified window. Optionally, certain
    values can be dropped from the sequences.
    Args:
        X (ndarray): N-dimensional sequence to iterate over.
        index (ndarray): Array containing the index values of X.
        window_size (int):  Length of the input sequences.
        target_size (int): Length of the target sequences.
        step_size (int):
            Indicating the number of steps to move the window forward each round.
        target_column (int): Indicating which column of X is the target.
        drop (ndarray or None or str or float or bool):
          Optional. Array of boolean values indicating which values of X are invalid,
          or value indicating which value should be dropped. If not given,
          `None` is used.
        drop_windows (bool): Optional. Indicates whether the dropping
           functionality should be enabled. If not given, `False` is used.
    Returns:
        ndarray, ndarray, ndarray, ndarray:
            * input sequences.
            * target sequences.
            * first index value of each input sequence.
            * first index value of each target sequence.
    """
    out_X = list()
    out_y = list()
    X_index = list()
    y_index = list()
    target = X[:, target_column]
    if drop_windows:
        if hasattr(drop, '__len__') and (not isinstance(drop, str)):
            if len(drop) != len(X):
                raise Exception('Arrays `drop` and `X` must be of the same length.')
        else:
            if isinstance(drop, float) and np.isnan(drop):
                drop = np.isnan(X)
            else:
                drop = X == drop
    start =0
    max_start = len(X) - window_size - target_size + 1
    while start < max_start:
        end = start + window_size
        if drop_windows:
            drop_window = drop[start:end+target_size]
            to_drop = np.where(drop_window)[0]
            if to_drop.size:
                start += to_drop[-1] + 1
                continue
        out_X.append(X[start:end])
        out_y.append(target[end:end+target_size])
        X_index.append(index[start])
        y_index.append(index[end])
        start = start + step_size
    return np.asarray(out_X), np.asarray(out_y), np.asarray(X_index), np.asarray(y_index)

class RandomWeightedAverage(Layer):
    def __init__(self, batch_size):
        """initialize Layer
        Args:
            batch_size: 64
        """
        super().__init__()
        self.batch_size = batch_size
    def call(self, inputs, **kwargs):
        """calculate random weighted average
        Args:
            inputs[0] x:   original input
            inputs[1] x_:  predicted input
        """
        alpha = K.random_uniform((self.batch_size, 1, 1))
        return (alpha * inputs[0]) + ((1-alpha) * inputs[1])
print("RandomWeightedAverage() Class defined, Done! ")

@tf.function
def critic_x_train_on_batch(x, z, valid, fake, delta):
    with tf.GradientTape() as tape:
        (valid_x, fake_x, interpolated) = critic_x_model(inputs=[x, z], training=True)
        with tf.GradientTape() as gp_tape:
            gp_tape.watch(interpolated)
            pred = critic_x(interpolated, training=True)
        grads = gp_tape.gradient(pred, interpolated)[0]
        grads = tf.square(grads)
        ddx = tf.sqrt(1e-8 + tf.reduce_sum(grads, axis=np.arange(1, len(grads.shape))))
        gp_loss = tf.reduce_mean((ddx-1.0) **2)
        loss = tf.reduce_mean(wasserstein_loss(valid, valid_x))
        loss += tf.reduce_mean(wasserstein_loss(fake, fake_x))
        loss += gp_loss*10.0
    gradients = tape.gradient(loss, critic_x_model.trainable_weights)
    optimizer.apply_gradients(zip(gradients, critic_x_model.trainable_weights))
    return loss

"""
Time Series anomaly detection functions.
Some of the implementation is inspired by the paper
https://arxiv.org/pdf/1802.04431.pdf
"""
class Anomaly(object):
    def __init__(self):
        pass
    def _deltas(self, errors, epsilon, mean, std):
        """Compute mean and std deltas.
        delta_mean = mean(errors) - mean(all errors below epsilon)
        delta_std = std(errors) - std(all errors below epsilon)
        Args:
            errors (ndarray): Array of errors.
            epsilon (ndarray): Threshold value.
            mean (float): Mean of errors.
            std (float): Standard deviation of errors.
        Returns:
            float, float:
                * delta_mean.
                * delta_std.
        """
        below = errors[errors <= epsilon]
        if not len(below):
            return 0, 0
        return mean - below.mean(), std - below.std()

    # anomalies.py  (2)
    def _count_above(self, errors, epsilon):
        """Count number of errors and continuous sequences above epsilon.
        Continuous sequences are counted by shifting and counting the number
        of positions where there was a change and the original value was true,
        which means that a sequence started at that position.
        Args:
            errors (ndarray): Array of errors.
            epsilon (ndarray): Threshold value.
        Returns:
            int, int:
                * Number of errors above epsilon.
                * Number of continuous sequences above epsilon.
        """
        above = errors > epsilon
        total_above =len(errors[above])
        above = pd.Series(above)
        shift = above.shift(1)
        change = above != shift
        total_consecutive = sum(above & change)
        return total_above, total_consecutive

    # anomalies.py  (3)
    def _z_cost(self, z, errors, mean, std):
        """Compute how bad a z value is.
        The original formula is::
                     (delta_mean/mean) + (delta_std/std)
            ------------------------------------------------------
            number of errors above + (number of sequences above)^2
        which computes the \"goodness\" of `z`, meaning that the higher the value
        the better the `z`.

<!-- p.86 -->
85
        In this case, we return this value inverted (we make it negative),
        to convert it into a cost function, as later on we will use scipy.fmin
        to minimize it.
        Args:
            z (ndarray): Value for which a cost score is calculated.
            errors (ndarray): Array of errors.
            mean (float): Mean of errors.
            std (float): Standard deviation of errors.
        Returns   float: Cost of z.
        """
        epsilon = mean + z * std
        delta_mean, delta_std =self._deltas(errors, epsilon, mean, std)
        above, consecutive =self._count_above(errors, epsilon)
        numerator =-(delta_mean / mean + delta_std / std)
        denominator = above + consecutive **2
        if denominator ==0:
            return np.inf
        return numerator / denominator

    def _find_threshold(self, errors, z_range):
        """Find the ideal threshold.
        The ideal threshold is the one that minimizes the z_cost function.
        Scipy.fmin is used to find the minimum, using the values from z_range as
        starting points.
        Args:
            errors (ndarray): Array of errors.
            z_range (list):
                List of two values denoting the range out of which the start points for
                the scipy.fmin function are chosen.
        Returns: float: Calculated threshold value.
        """
        mean = errors.mean()
        std = errors.std()
        min_z, max_z = z_range
        best_z = min_z
        best_cost = np.inf
        for z in range(min_z, max_z):
            best = fmin(self._z_cost, z, args=(errors, mean, std), full_output=True,
            disp=False)
            z, cost = best[0:2]
            if cost < best_cost:
                best_z = z[0]
        return mean + best_z * std
    def _fixed_threshold(self, errors, k=3.0):
        """Calculate the threshold.
        The fixed threshold is defined as k standard deviations away from the mean.
        Args:
            errors (ndarray): Array of errors.
        Returns:
            float: Calculated threshold value.
        """
        mean = errors.mean()
        std = errors.std()
        return mean + k * std

    def _prune_anomalies(self, max_errors, min_percent):
        """Prune anomalies to mitigate false positives.
        This is done by following these steps:
            * Shift the errors 1 negative step to compare each value with the next one.
            * Drop the last row, which we do not want to compare.
            * Calculate the percentage increase for each row.
            * Find rows which are below ``min_percent``.
            * Find the index of the latest of such rows.
            * Get the values of all the sequences above that index.
        Args:
            max_errors (pandas.DataFrame): DataFrame object containing columns ``start``, ``stop`` and ``max_error``.
            min_percent (float):

                highest non-anomalous error in the window sequence.
        Returns:
            ndarray: Array containing start, end, max_error of the pruned anomalies.

        next_error = max_errors['max_error'].shift(-1).iloc[:-1]
        max_error = max_errors['max_error'].iloc[:-1]

        too_small = increase < min_percent
        if too_small.all():
            last_index =-1
        else:

        return max_errors[['start', 'stop', 'max_error']].iloc[0: last_index+1].values

    def _compute_scores(self, pruned_anomalies, errors, threshold, window_start):
        """Compute the score of the anomalies.
        Calculate the score of the anomalies proportional to the maximum error in the sequence
        and add window_start timestamp to make the index absolute.
        Args:
            pruned_anomalies (ndarray): Array of anomalies containing the start, end and max_error for all anomalies in the window.
            errors (ndarray): Array of errors.

            max_error = row[2]
            score = (max_error-threshold) / denominator
            anomalies.append([row[0]+window_start, row[1]+window_start, score])
        return anomalies

        We iterate over a list of start, end, score triples and merge together
        overlapping or consecutive sequences.
        The score of a merged sequence is the average of the single scores,
        weighted by the length of the corresponding sequences.
        Args:
            sequences (list): List of anomalies, containing start-index, end-index, score for each anomaly.
        Returns:
            ndarray: Array containing start-index, end-index, score for each anomaly after merging.

            if sequence[0] <= prev_sequence[1] +1:

되는 충격을 견디면서도 악조건의 환경에서도 버틸 수 있도록 안정성과 내구성이 갖춰져

- 또한, 배터리팩은 지속적으로 관리되지 않으면 수명에 영향을 미칠 수 있으므로 제품 생
산부터 시험까지 품질관리에 특별히 주의가 필요하다.
- 실제 E공장에서는 배터리팩을 구성하는 최소 단위인 배터리셀 하나의 불량으로 인해 주
변 배터리셀을 구성하는 모듈 전체를 교체해야 하는 경우가 발생하고 있어 불량 배터리를
사전에 발견하여 처리할 수 있는 방안들을 도입하고 있으며, 최적의 상태를 유지하기 위
해 지속적으로 모니터링하기 위한 기반을 구축하고 있는 상황이다.
- 본 분석의 결과는 배터리 제품의 품질관리가 필요한 제조현장에서 적용될 수 있다고 판단
된다. 즉, 제조현장에서 운용중인 설비를 통해 공정 데이터를 수집하고, 이를 기반으로 품
질검사 데이터를 확보하여 데이터셋을 구성할 수 있는 경우 해당 모델을 적용하여 유의미
한 결과를 도출할 수 있다.
- 실제 배터리팩은 적게는 수십개에서 많게는 수백개의 배터리셀들로 구성되어 있으며, 일

알고리즘을 채택하고 이러한 이상 탐지에 적합한 MTadGAN(Multivariate Time Series
Anomaly Detection by Generative Adversarial Network) 같은 적대적 생성 모형을
적용할 수 있다.
- 또한, 배터리팩 품질관리에 제한되지 않고 최소 단위인 배터리셀들의 품질까지 관리할 수
있으므로 배터리셀 또는 배터리모듈 생산에 특화되어 있는 제조현장에 본 분석이 적용될
수 있다.

def getSeriesValidity(data, range_min, range_max):
    column_name = data.name
    total_data = data.count()
    if(len(column_name) >=4 and column_name[0:4] =='Time'):
        time_conv = pd.to_datetime(data).dt.time
        temp = data.loc[time_conv >= range_min]
        temp = data.loc[time_conv <= range_max]
        in_range_data = temp.count()
    elif(len(column_name) >=4 and column_name[0:4] =='Date'):
        date_conv = pd.to_datetime(data).dt.date
        temp = data.loc[date_conv >= range_min]
        temp = data.loc[date_conv <= range_max]
        in_range_data = temp.count()
    else:
        in_range_data = data.loc[(data >= range_min) & (data <= range_max)].count()
    validity = in_range_data / total_data *100
    return validity
def getValidity(data, ranges):
