분석 목적

- 로봇 용접기는 팁 깨짐, 축 기어 고장, 머신 벨트 늘어짐 등 다양한 원인으로 고장이 발생할 수 있으며,
이는 용접 불량을 초래하기도 한다.
- 모터, 기어 등 로봇 용접기의 핵심 부품은 진동을 발생시키고, 일정한 전류공급은 용접 품질과 관련되어
있다.
- 따라서, 로봇 용접기의 정상적인 동작과 용접 품질 상태를 모니터링할 수 있는 기술이 요구된다.
- 로봇 용접기에서 발생 되는 진동과 전류 데이터를 이용해, 로봇 용접기의 이상 동작과 용접 품질 상태를
감지할 수 있는 AI 모델 제시를 목표로 한다.

1) 공정(설비) 개요
• 로봇 용접
- 용접(welding)은 금속, 유리, 플라스틱 등 대상체를 열과 압력으로 접합하는 기술로
제조업 분야에서 매우 중요한 기술이다.
- 로봇 용접은 미리 정의된 프로그램에 따라 용접작업을 수행함으로써, 용접과정에서
발생할 수 있는 각종 사고를 예방하고 작업물의 품질을 일정 수준 이상으로 유지하는
장점이 있다.
- 대상 공정은 엘리베이터 비상정지 장치 제조공정 중 로봇 용접 공정으로 로봇 용접기

2) 이슈사항(Pain point)
• 공정(설비)상의 문제 현황
- 현재, 로봇 용접기 등 공정 핵심 설비의 고장징후를 이상 소음 발생 등 관리자의 운영
경험에 의존해 대응하는 수준으로, 해당 소음과 이상징후의 직접적인 관련성을 판단
하기 어렵다.
- 또한, 다양한 형태의 용접 불량상황이 발견되고 있지만 이에 대한 사후대처도 현장 관
리자의 경험에 전적으로 의존하는 상황이다.
- 주요 설비의 원활한 운영을 위해서는 객관적인 데이터에 근거한 정확한 예측을 통해
설비의 가동 중단에 따른 생산 손실을 줄일 수 있는 대책이 요구된다.
- 특히, 결함 검출 시기가 늦어질수록 보수비용과 생산 손실이 급증하기 때문에, 초기
단계에 이를 인지하고 대응하는 것이 중요하다.
- 결과적으로, 로봇 용접기의 고장 예방과 품질 불량을 감지할 수 있는 AI 기반 공정 감
시 시스템 구축이 필요하다.
• 문제해결 장애요인
- 로봇 용접기의 고장진단과 품질 확인을 위한 정량적인 데이터가 확보되어 있지 않아
분석에 어려움이 있으며, 짧은 시간 내 충분한 이상(결함) 데이터 확보가 현실적으로
어렵다.
- 로봇 용접기의 고장과 품질 불량은 다양한 요인으로 발생하기 때문에, 상대적으로 성
능이 우수한 지도학습 (supervised learning) 알고리즘을 적용하기 어렵다.
• 극복 방안
- 로봇 용접기의 고장진단과 용접 품질 불량을 감지하기 위해, 로봇 용접기의 정상 동작
상황에서 충분한 진동, 전류 데이터를 확보한다.
- 무선 설비 상태 모니터링(wireless asset health monitoring) 솔루션에서 감지한 이
상 데이터를 수집하고 활용한다.
- 고장진단을 위해 로봇 용접 시 발생하는 설비의 물리적인 움직임에 대한 진동 데이터
와 용접 불량을 검출하기 위한 전류 데이터를 비지도 학습(unsupervised learning)
알고리즘에 적용한다.

1.2 분석 목표
1) 분석 목표
- 용접 공정 중 발생하는 로봇 용접기의 진동과 전류 데이터를 이용해 설비의 결함징후와
용접 품질 예측을 수행하는 AI 모델을 개발하고, 현행 엘리베이터 비상정지 장치 용접
공정에 적용함으로써, 설비 이상징후 감시를 통해 결함을 사전 예방할 수 있다.
2) 데이터 정의 및 소개
- 진동은 설비 운영 중 필수적으로 발생하는 요소로, 고유한 형태의 패턴을 나타내며, 특
정 주파수 영역에 따라 설비상태에 대한 다양한 정보를 얻을 수 있다.
- 제조 현장의 거의 모든 설비에서 진동이 발생하며, 특히 모터, 기어 등 설비의 핵심 부
품에서 대부분 진동이 발생하기 때문에 이들 핵심 부품의 진동 상태를 감시함으로써 설
비의 고장 발생 여부를 진단할 수 있다.
- 전류는 전선을 통해 흐르는 전기의 양으로, 로봇 용접기의 경우 용접 품질 유지를 위해
서는 일정하게 유지되어야 한다. 용접작업 중 발생하는 전류 데이터를 이용해 용접기의
상태 모니터링과 더불어 용접 품질 불량 발생 원인을 찾아볼 수 있다.
- 따라서, 로봇 용접기에 진동 센서를 부착하고, 로봇 용접기 주 전원선에 전류 센서를 부
착해 해당 데이터를 취득했다.
[그림 3] 로봇 용접기에 설치된 진동 센서(좌)와 전류 센서(우)
- 진동, 전류 센서 데이터는, 현장에 설치된 수신기와 엣지 컴퓨터에 수집되고, 산업용 자
동화 애플리케이션을 위한 공급자 독립형 통신프로토콜인, OPC-UA(Open Platform
Communications Unified Architecture)를 통해 원격으로 데이터를 저장, 확인했다.
- 수집된 데이터는 무선 설비 상태 모니터링 솔루션의 대시보드(dashboard)로 확인할
수 있으며, 2021년 8월 한 달 동안 수집된 정상 진동 데이터와 비정기적으로 발생한 이
상 진동 데이터를 대시보드로 확인하고 활용했다.

3) 데이터 분석 기대효과
- 제조 현장에서 주요 설비의 예지보전을 위해서는, 해당 설비의 정상, 이상 구동 상태를 판
단할 수 있는 적합한 센서를 이용해 관련 데이터를 취득하고 분석하는 과정이 필요하다.
- 설비 예지보전과 고장진단에는 진동, 전류, 소음, 온도, 압력 등 다양한 데이터가 설비
특성에 따라 선택적으로 적용되고 있다.
- 특히, 대부분 제조 설비는 구동 중 진동을 동반하고 전력을 소모하기 때문에 설비에서
수집된 진동, 전류 데이터는 고장예측을 위한 필수 데이터로 활용될 수 있다.
- 로봇 용접기 예지보전 분석 사례를 통해, 설비 예지보전을 위한 AI 모델 구성 방법과 진
동, 전류 데이터를 이용한 AI 모델 학습 과정을 유사 데이터에 적용할 수 있다.
- 또한, 분석 사례에서 소개된, AI 모델을 활용한 이상 신호 탐지 방법은 타 설비의 결함
검출에 응용할 수 있다.

• 데이터 품질 지수
- 완전성(Completeness) : 필수항목에 누락이 없어야 한다.
- 유일성(Uniqueness) : 데이터 항목은 유일해야 하며 중복돼서는 안 된다.
- 유효성(Validity) : 데이터 항목은 정해진 데이터 유효범위 및 도메인을 충족해야 한다.
- 일관성(Consistency) : 데이터가 지켜야 할 구조, 값, 표현되는 형태가 일관되게 정의
되고, 서로 일치해야 한다.

- 정확성(Accuracy) : 실제 존재하는 객체의 표현 값이 정확히 반영되어야 한다.
- 무결성(Integrity) : 데이터베이스 자료의 오류 없이 변화에 영향을 받지 않고 데이터

유효성 품질지수 = (유효성 만족 데이터 수 / 전체 데이터 수) × 100

- 데이터 측정 시각에 대해 날짜 시간의 표현이 올바른지 검사하고 일관성 품질지수를

2) AI 분석모델
• 해당 AI 방법론(알고리즘) 선정 이유
- 설비 결함 발생 원인은 다양하므로, 실제 제조 현장에서 결함 유발 인자(factor)를 식
별하고, 관련 데이터를 취득하는 것은 현실적으로 많은 어려움이 따른다.
- 따라서, 상대적으로 쉽게 데이터 취득이 가능한 정상 데이터를 학습한 모델을 이용해
설비 결함을 식별하는 것이 현실적인 접근방법이다.
- CNN(Convolutional Neural Network)은 일반적으로 2차원 이미지 특징 추출에 주
로 사용되는 AI 모델이지만, 고정된 크기의 1차원 시계열 데이터에서 중요 정보를 추
출하는 데에도 유용하다. 본 가이드북에서 제공하는 진동 데이터와 전류 데이터는 각
각 512, 1,024개의 고정된 데이터 길이를 갖는다.
- 또한, 원본 데이터를 다시 복원하는 학습모델인 Autoencoder는 정상 데이터로부터
이상 데이터를 식별하는 이상 탐지(anomaly detection)문제 해결에 주로 활용된다.
- 결과적으로, 비지도 학습방식, 데이터의 고정된 길이, 이상 탐지 성능 등을 고려해 분
석모델로 Convolutional Autoencoder를 선정했다.
• 적용하고자하는 AI 분석 방법론(알고리즘)의 구체적 소개
- Autoencoder는 비지도 학습의 가장 기본적인 형태로, 입력 데이터(input data)를
보다 작은 차원의 데이터로 압축하는 인코더(encoder)와 압축된 데이터에서 다시 원
래 차원으로 복원하는 디코더(decoder)로 구성된다.
- 즉, 입력 데이터를 최대한 복원한 출력 데이터를 학습하는 딥러닝 모델이다. 이때, 입
력 데이터를 원본 데이터, 출력 데이터를 복원 데이터라고도 하며, 원본 데이터와 복

13
원 데이터 사이에 발생한 차이를 복원 오차라고 한다.
- 복원 오차는 일반적으로 학습 때 등장하지 않았던 새로운 패턴의 데이터에 대해 상대
적으로 크게 나타나기 때문에, 이러한 Autoencoder 모델의 특성은 이상 탐지 문제에
효과적으로 적용할 수 있다.
- Convolutional Autoencoder는 인코더, 디코더에 1차원 합성곱층을 활용한 모델로
입력(원본) 데이터를 인코더와 디코더를 거쳐 최대한 입력 데이터와 유사한 출력(복
원) 데이터를 생성을 학습하는 모델이다.
[그림 9] Conv-AE 모델 구조
- 입력 데이터와 출력 데이터의 차이(복원 오차)를 계산하는 방법은 여러 가지가 있지
만 본 실습에서는 평균 절대 오차(MAE, Mean Absolute Error)를 이용한다. MAE는
입력 데이터와 출력 데이터의 절댓값 차이의 평균값으로 계산된다.
- MAE는 학습에 사용된 데이터와 유사한 패턴의 경우 작은 값을 갖고, 패턴이 상이할
수록 큰 값을 갖는다.
- 따라서, 정상적으로 작업 중인 로봇 용접기의 진동, 전류 데이터를 학습한
Convolutional Autoencoder 모델은 이상(결함) 데이터에 대해 상대적으로 큰 MAE
값을 갖게 되어 로봇 용접기의 정상 상태와 결함 상태를 효과적으로 구분(분류, 식별)
할 수 있다.
- 이때, 정상 상태와 결함 상태를 구분하는 MAE 값을 임계치(threshold)라고 한다.

- 본 실습에서는 3 시그마 규칙(three sigma rule)을 적용해 학습 데이터 MAE 분포 값
의 3 표준편차 범위(99.7%) 값을 임계치로 이용하며, 임계치보다 작은 MAE 갖는 데
이터는 정상 상태로, 임계치보다 큰 MAE를 갖는 데이터는 결함 상태로 구분한다.

- 로봇 용접기의 용접 공정 중 발생하는 진동 데이터와 전류 데이터를 이용해 로봇 용

① 패키지/데이터 불러오기 : 분석에 필요한 파이썬 패키지를 선언하고, 제공된 데이터셋의 내용
을 표 형식과 그래프 형식으로 확인한다.
② 데이터 탐색 : 데이터셋(진동, 전류)의 데이터 구성과 통계치를 확인한다.
③ 데이터 전처리 : 데이터셋(진동, 전류)을 학습용과 평가용으로 분리하고, AI 모델 적용을 위한

④ AI 모델 구축 : 순차 모델(sequential model) 방식으로 Convolutional Autoencoder 모델
을 함수로 작성한다.
⑤ AI 모델 학습 : 학습 데이터셋(진동, 전류)을 이용해 진동과 전류 데이터에 대한 모델을 학습하
고, 각 학습 결과를 확인한다.
⑥ 임계치 설정 : 학습 데이터셋(진동, 전류)의 복원 오차를 확인하고, 3 시그마 규칙(three
sigma rule)을 적용해 각각 임계치(threshold)를 결정한다.
⑦ AI 모델 평가 : 임계치를 이용해 평가 데이터셋(진동, 전류)의 데이터를 평가(정상, 진동, 이상
진동, 정상 전류, 이상 전류)하고, 그래프로 가시화하여 결과를 확인한다.
⑧ 결과분석 : 분석 결과를 토대로 활용방안을 설명한다.

def Conv_AE(input_dataset):
    model = Sequential()
    model.add(Input(shape=(input_dataset.shape[1], input_dataset.shape[2])))
    model.add(Conv1D(filters=64, kernel_size=input_dataset.shape[1] // 64, padding='same', strides=2,
activation='relu'))
    model.add(Conv1D(filters=32, kernel_size=input_dataset.shape[1] // 64, padding='same', activation='relu'))
    model.add(Conv1DTranspose(filters=64, kernel_size=input_dataset.shape[1] // 64, padding='same', strides=2,
activation='relu'))
    model.add(Conv1DTranspose(filters=1, kernel_size=input_dataset.shape[1] // 64, padding='same'))

    return model
