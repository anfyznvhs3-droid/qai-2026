간략소개
PyCaret은 scikit-learn 패키지를 기반으로 하는 AutoML 라이브러리이다. 이 패키지는 데이터 전처리

의 하이퍼 파라미터 tuning 및 ensemble 모델 구축으로 최적화된 기계학습 모델을 선정할 수 있다.

• 자동차 프레임 및 차체 제작 연속공정
- 자동차 자체의 외형 및 차체 프레임을 제작하기 위해 연속된 프레스에 정해진 원자재
를 상하 양측의 금형 내에 투입하고, 고압의 기계적인 타격으로 원하는 형상을 제작하
는 공정이다.
- 제품의 강도와 치수 정밀도가 높고, 기계적 성질이 우수며 금형 제작비가 비싸 대량의
제품생산에 적합하다.
- 특히, 연속공정에 의한 제품생산으로 특정 설비의 고장이나 이상으로 대량의 손실이
발생할 수 있으며, 해당 설비들의 공정 균형이 중요하다.

2) 이슈사항(Pain point)
• 공정(설비)상의 문제 현황
- 자동차 차체 생산은 제품의 투입과 취출에 사용되는 산업용 로봇, 원자재의 소성변형
을 유도하는 프레스 설비, 형상으로 만들어진 재공품을 최종 완제품으로 만들기 위한
용접 설비 등이 필요하다.
- 자동차용 단조프레스 공정은 제품의 형상에 따라 정해진 금형 틀에 연속적으로 가압
하여 원하는 형태의 제품을 생산하게 되는데, 이때 연속공정에 사용되는 같은 설비 제
원이라고 하더라도 설비의 상태(구동 모터, 감속기, 베어링 등의 마모)에 따른 에너지
소모량에 차이가 발생할 수 있다.
- 소성가공에 사용되는 프레스 설비의 에너지 사용 모니터링은 에너지 자원 최적화를
통한 제품생산 비용 절감에 효과가 있을 것으로 예상되나 관련된 기술분석 자료가 부
족한 상황이다.
• 문제해결 장애요인
- 제조 현장 특성상, 설비의 전력 사용량을 측정하기 위해 기 구축된 전력공급시스템에
별도의 전력량계를 부착하고 에너지 모니터링 시스템을 구축하는 것은 데이터 수집
과정에 많은 노력이 수반된다.
- 또한, 설비의 에너지 사용량과 관련 공정 데이터에 다양한 분석 방법을 적용하기 위해
서는 데이터 탐색, 특징 추출, 모델 선정, 훈련 및 최적화 등 도메인 전문 지식이 요구
된다.
• 극복 방안
- 프레스 연속공정에 사용되는 주요 설비의 에너지 소모량을 측정하기 위해 현장의 관
련 설비에 전류 센서를 설치하고, 무선 설비 상태 모니터링(wireless asset health
monitoring) 솔루션을 이용해 원격으로 데이터를 취득하고 활용한다.
- 자동 기계학습(AutoML, Automated Machine Learning) 기법을 적용해, 비전문가
도 다양한 ML(Machine Learning) 알고리즘을 활용해 에너지 사용량을 분석하고,
각 알고리즘의 성능 비교를 통해 자원 최적화 방안을 도출할 수 있도록 한다.

1) 분석 목표

2) 데이터 정의 및 소개
- 전류는 전선을 통해 흐르는 전기의 양을 의미하며, 제조 현장에서 주요 설비 운행 중 계
속해서 소모된다. 전류는 전류 센서(current sensor)를 이용해 측정 가능하며, 이를 이
용해 설비의 전력량을 파악할 수 있다.
[그림 3] 설치된 전류 센서 로봇(좌), 프레스(우)
- 전류의 세기는 암페어(A) 단위로 측정되며 1초 동안 전선의 단면을 통과하는 전하량으
로 정의된다. 전류 데이터는 시간에 따라 변하기 때문에 대푯값으로 최댓값, 평균값, 실
횻값 등을 이용한다.
- 이 중 실횻값은 전류가 실제로 일한 양을 의미하고, 전류 파형 신호의 제곱(square)에
시간 평균(time average)을 구하여 제곱근(square root)을 취하는 RMS(Root Mean
Square) 값이 전류 데이터 분석에 주로 활용된다.
[그림 4] 전류 데이터 모니터링 전류(좌), RMS(우)

3) 데이터 품질 전처리
• 데이터 품질 전처리 목적
- 실제 공정에서 발생하는 데이터들은 값이 의미 없거나 누락 및 오타가 발생하여 데이
터 품질이 떨어진다.
- 아무리 좋은 분석 방법론을 가지고 있더라도 품질이 낮은 데이터를 이용하면 좋은 결
과를 얻을 수 없으므로, 데이터 품질 전처리는 데이터 분석에서 가장 중요한 단계이다.
- 따라서, 데이터들의 6가지 품질지수를 파악하고, 데이터 전처리를 통해 품질지수를
향상한다.
• 데이터 품질 지수
- 완전성(Completeness) : 필수항목에 누락이 없어야 한다.
- 유일성(Uniqueness) : 데이터 항목은 유일해야 하며 중복돼서는 안 된다.
- 유효성(Validity) : 데이터 항목은 정해진 데이터 유효범위 및 도메인을 충족해야 한다.
- 일관성(Consistency) : 데이터가 지켜야 할 구조, 값, 표현되는 형태가 일관되게 정의
되고, 서로 일치해야 한다.
- 정확성(Accuracy) : 실제 존재하는 객체의 표현 값이 정확히 반영되어야 한다.
- 무결성(Integrity) : 데이터베이스 자료의 오류 없이 변화에 영향을 받지 않고 데이터
의 유일성, 유효성, 일관성이 보호돼야 한다.
• 데이터 품질 지수 세부 설명
완전성 품질지수 = (1 - (결측치 데이터 수 / 전체 데이터 수)) × 100
- pandas 라이브러리의 DataFrame 객체 isna() 함수를 이용해 결측치 데이터 수를
구하고, len() 함수를 이용해 전체 데이터 수를 구한 후 완전성 품질지수를 측정한다.
유일성 품질지수 = (유일한 데이터 수 / 전체 데이터 수) × 100
- pandas 라이브러리의 DataFrame 객체 unique() 함수를 이용해 유일한 데이터 수
를 구하고, 유일성 품질지수를 측정한다.
유효성 품질지수 = (유효성 만족 데이터 수 / 전체 데이터 수) × 100
- 전류 데이터는 음수값이 기록될 수 없다. 따라서 전체 데이터값에 대해 음수값 여부를
판별하고 유효성 품질지수를 측정한다.

일관성 품질지수 = (일관성 만족 데이터 수 / 전체 데이터 수) × 100
- 데이터 측정 시각에 대해 날짜 시간의 표현이 올바른지 검사하고 일관성 품질지수를

정확성 품질지수 = (1 - (정확성 위배 데이터 수 / 전체 데이터 수)) × 100
- AI 모델 학습에 사용되는 정상 신호 데이터에 대해 측정 기간이 정확한지 검사하고
정확성 품질지수를 측정한다.
무결성 품질지수 = (유일성, 유효성, 일관성 지수중 100%가 되는 지수 개수 / 3) × 100
- 계산된 유일성, 유효성, 일관성 품질지수를 이용해 무결성 품질지수를 측정한다.
가중치 지수 = 품질지수 × 가중치
- 안전성, 유일성, 유효성, 일관성 정확성, 무결성 품질지수에 각 0.2, 0.2, 0.2, 0.15,
0.15, 0.1의 가중치를 부여하고 가중치 지수를 계산한다.
데이터 품질지수 = ∑가중치 지수
- 각 품질지수와 가중치를 이용해 종합적인 데이터 품질지수를 측정한다.

① PyCaret 회귀 모듈
○ 회귀(Regression) 모델은 지도학습의 가장 기본적인 형태로, 독립변수들에 대한 입력 데이
터(input data)를 통해서 원래 종속변수의 값을 예측하는 모델이다.
○ 이러한 회귀 모델의 목적은 판매량, 생산량, 온도 등 연속적인 값을 가지는 종속변수들을 예
측한다.
○ PyCaret 회귀 모듈은 이러한 하나의 종속변수와 한 개 혹은 그 이상의 독립변수들 사이의
관계를 학습하여 추정하는 데에 사용된다.
○ 이 과정에서 PyCaret은 선형 회귀, Lasso 회귀, 의사결정나무 회귀 등 25개의 널리 쓰이는
회귀 모델들을 학습하고 각 모델들의 성능을 비교하여 최고의 성능을 보이는 모델을 선택한다.
○ 최고의 성능을 보이는 모델을 선택하는 데에 있어서 PyCaret은 모델들의 교차 검증을 통하
여 다양한 성능 지표들을 비교하며, 평균 절대 오차(MAE, Mean Absolute Error)를 이용
한다.
○ MAE는 입력 데이터와 출력 데이터의 절댓값 차이의 평균값으로 계산된다.

○ 약한 외생성: 독립변수를 확률 변수가 아니라, 고정된 값으로 취급하며, 이는 설명 변수가 에

짐을 의미한다.
○ 오차의 독립성: 독립변수의 오차가 서로 무관함을 가정한다.

- 랜덤 포레스트(Random forest) 회귀
○ 랜덤 포레스트는 분류, 회귀를 위한 앙상블 학습 방법을 통해 다수의 의사결정 나무들을 구

○ 회귀 작업의 경우 개별 의사결정 나무로부터 도출된 결과의 평균을 반환한다.
○ 랜덤 포레스트는 개별 의사결정 나무들을 학습할 때 발생할 수 있는 과대적합(Overfitting)
문제를 해결할 수 있다.
○ 랜덤 포레스트의 가장 큰 특징은 랜덤성에 의해 모델을 구성하는 각 의사결정 나무마다 다른
특성을 가진다는 점이다.
○ 즉, 각 의사결정 나무마다 원래 종속변수 값을 예측하기 위해 사용되는 독립변수의 종류들이
다르다.
○ 이러한 특성을 통해 각 의사결정 나무들의 예측들이 비상관성을 가지게 되며 이는 일반화 성
능의 증가로 이어진다.
○ 포레스트의 크기, 즉, 모델을 구성하는 의사결정 나무의 개수는 랜덤 포레스트에 가장 큰 영
향을 미치는 파라미터 중 하나이다.
○ 포레스트의 크기가 작으면 모델을 학습하는데 걸리는 시간이 짧아지지만, 일반화 성능이 떨
어지며, 포레스트의 크기가 커지면 학습을 하는데 걸리는 시간은 더 길어지지만 크기가 작을
때에 비해 예측값의 연속성과 일반화 성능이 모두 증가한다.
○ 따라서, 랜덤 포레스트 학습을 위해서는 충분한 크기의 포레스트의 크기를 정하는 것이 중요
하다.

인덱스가 DataFrame의 행(axis=0) 또는 열 (axis=1)인 series개체이다. lambda는
apply 함수가 적용되는 행 또는 열의 요소를 특정할 수 있는 명령어다.
