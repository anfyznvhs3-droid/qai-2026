1. 분석 개요
1.1 분석 배경
1) 공정(설비) 개요
• 제조현장 안전관리 정의 및 특징
- ‌산업에서 제품 생산 및 공정에 사용하는 설비와 설비를 조작하고 사용하는 작업자가
활동하는 영역을 제조현장이라고 한다. 제조현장에서는 일반적으로 설비 조작 및 가
동에서 오는 위험과 작업자의 안전 부주의에서 비롯한 위험이 발생할 수 있다.
- 하지만 작업자가 생산 활동을 하면서 일일이 설비에 대하여 상시 모니터링을 할 수 없
을 뿐만 아니라, 설비 외에 다른 물리적, 전기적, 화학적 사고 등의 발생에 대해 대비를
할 수 없다. 특히, 공장 가동 시간 외에 발생하는 대표적인 사고인 화재는 단순 모니터
링 시스템만으로 예방하기에는 역부족이다.
- 이러한 위험 및 사고를 예방하기 위해, 대부분의 산업 현장에서는 감독관 뿐만 아니라
CCTV 영상 모니터링을 이용하고 있다.
• 영상 기반 감시 시스템 정의 및 특징
- 영상 기반 감시 시스템(VSS, Video Surveillance System)은 범죄 예방, 재난 감시
등 국민의 생명과 재산을 보호하기 위한 시스템으로서 카메라, 전송 장치, 저장 및 재
생장치 등으로 구성되며, 국제 표준화 기구인 IEC(International Electrotechnical
Commission)에서는 CCTV(Closed Circuit Television)를 영상 감시 시스템으로 칭
하고 있으며, 국내에서는 영상 보안 시스템 등으로 불리고 있다.
- 이러한 기술을 활용하는 분야는 점점 다양해지고 있으나, 아직 열악한 제조 현장에서
는 주변 환경의 영향과 작업자들의 거부감 등으로 설비 감시, 안전 감시 시스템 보급이
크게 이루어지지 않고 있고 있다.
• AI 기반 안전관리 시스템
- 딥러닝 기술을 활용한 영상 기술 AI 모델은 기존에 사용해왔던 영상 기술에 비해 반응
시간과 성능 면에서 더 좋은 결과를 보이고 있다. 이러한 딥러닝 기술을 영상 보안 시
스템에 접목시킨 AI 기반 모델을 통해 공장, 사무동 등을 대상으로 안전관리 시스템을
적용한다.

2) 이슈사항(Pain point)
• 공정(설비)상의 문제 현황
- ‌대부분의 생산 현장에서 작업자는 다양한 설비를 이용하여 생산 활동을 한다. 작업자
의 안전을 위해 모든 생산 현장에는 작업자가 지켜야 할 안전 수칙이 있을 뿐만 아니
라, 이를 관리 및 감독하는 감독관이 함께 있다. 이에 더하여, 현장 내 CCTV 설치를
통해 작업자의 안전과 설비 이슈, 그 외에 다른 전기적, 화학적 사고 발생을 미리 감지
하고 대비하기 위한 영상 기반 감시 시스템을 운영하고 있다.
- 해당 분석 실습에서 적용한 프레스기의 경우, 작업자가 설비에서 일정한 안전거리를
두고, 설비를 조작하여 작업을 진행하며, 프레스기가 작동을 하는 동안에는 작업자가
해당 안전거리를 유지하고 있기 때문에 안전사고가 발생하지 않는 편이다. 하지만, 프
레스기의 지속적인 운영을 위해서는 제품 생산 과정에서 작업대 위에 발생하는 부산물
및 폐기물을 작업자가 직접 제거해주어야 한다는 이슈가 있다. 이 과정은 작업자가 설
비를 조작하는 과정에 비해 작업자의 안전에 대해 더 직접적인 위험 요소가 존재한다.
따라서, 타 작업 과정보다 더 엄격한 안전관리를 요한다.
• 문제해결 장애요인
- ‌본 분석 실습에서는 작업 현장 내 설치된 CCTV에서 취득한 영상을 활용하여 분석을
진행한다. 생산 현장에서 작업 중인 작업자와 설비 촬영 시, 작업 시간에 따른 외부 날
씨 및 생산 현장 내 조명의 밝기에 따라 취득한 영상의 품질이 달라진다. 예를 들어,
생산 현장 내 창문을 통해 들어오는 외부의 빛이 반사되거나, 야간 작업 시 사용하는
내부 조명의 밝기에 따라 취득한 영상의 전체 밝기와 같은 영상 품질이 달라지게 된
다. 따라서 외부 요인에 따른 영향을 줄이기 위해 CCTV 카메라를 설치할 최적의 위

- 또한 작업자가 설비에 근접하여 작업을 수행할 경우, 작업자의 위험도를 최대한 줄이

영상의 품질 저하를 최대한 줄일 수 있는 위치를 파악하여 CCTV 설치 및 셋업을 진
행한다.
- 취득 영상을 통한 AI 모델 학습을 통해 작업자를 판별하고, 설비를 기준으로 안전 관
리 영역을 설정한다. 작업자가 해당 영역에 상주하는 동안 안전에 더 유의하고 모니터
링할 수 있도록 알람을 발생시키고자 한다.
1.2 분석 목표
1) 분석 목표
본 분석은 프레스기를 활용한 실제 생산 현장에서 작업자의 영상을 활용하여 검출하고,
안전 영역 설정에 따른 작업자의 안전 유무를 감지하여 그에 따른 알람 시스템 동작을 목
표로 한다.
2) 데이터 정의 및 소개
본 분석에서 활용되는 안전관리 데이터는 프레스기를 사용하는 실제 작업 현장 내 CCTV
를 통해 얻은 작업 영상이 포함되며, CCTV 동영상에 대해 일정 시간별 이미지에 대한 데
이터가 기록된다. 이미지 외에도 작업자의 영역을 표시한 경계 박스의 정보도 데이터에
포함되어 있다.

- 심층 신경망(Deep Neural Network)
◦ 심층 신경망(Deep Neural Network)은 신경망이라 부리는 구조를 연속적으로 깊
게 쌓은 후 분류 및 회귀 등의 다양한 목적을 위해 학습시키는 AI 알고리즘이다. 신
경망은 [그림 5]처럼 여러 노드로 구성되어 있으며 은닉층(hidden layer)이라고도
불린다. 신경망에 속하는 노드는 입력층의 데이터를 받고 행렬 곱 등의 연산을 거친
후 결과값을 출력한다. 이러한 신경망은 선형적인 변환뿐만 아니라 여러 활성화 함
수(activation function)라 부르는 비선형적인 연산을 수행하기도 한다.
◦ 활성화 함수는 일반적으로 시그모이드(sigmoid) 함수와 정류 선형 유닛(Rectified
Linear Unit) 함수를 사용한다. 정류 선형 유닛 함수는 0보다 작은 입력은 0으로 만
들고, 0보다 큰 입력은 그대로 출력한다. 시그모이드 함수는 입력값을 0과 1사이의
결과값으로 제한한다. 신경망의 이러한 특성은 여러 층으로 연속적으로 쌓을수록 진
가를 발휘하는데, 매우 깊은 신경망은 수많은 함수를 구현할 수 있다는 장점이 있다.

◦ 신경망은 일반적으로 경사 하강법이라는 기법을 사용하여 학습을 진행한다. 신경망

◦ 분류작업을 위한 심층 신경망은 임의의 다수 신경망을 연속적으로 쌓고, 최종적으로

노드별 활성화 함수, 신경망의 개수, 손실 함수 등의 조작 가능한 값이 매우 많이 존재한

◦ 모델의 학습 진행 상황을 판단하는 손실 함수(loss function)는 학습 목표에 따라

장 많이 사용하며, 이는 실제 목표치(0 또는 1)에 근접할 때 낮은 값을 가지고, 반대
의 경우에는 큰 값을 가진다.

[그림 9] Feature Pyramid Network
◦ FPN은 [그림 9]와 같이 컨볼루션과 연결(concatenate)을 통해 크기가 다른 특징
맵을 생성하게 된다. 큰 객체(Large Object)의 경우 255x13x13의 특징 맵은 입력

색에 크기와 종횡비가 다른 3개의 앵커 박스(Anchor box)가 사용되기 때문에 각 셀
마다 (class의 개수 + 경계박스의 x,y,w,h + 객체 존재 확률) x 앵커 박스 개수, 즉
(80 + 4 + 1)x3=255개의 채널을 가지게 된다. 중간 객체(medium object)와 작은
객체(small object)에 대해서도 같은 방식으로 경계 박스가 탐색 된다. 욜로는 탐색
된 경계 박스에서 박스가 겹친 정도를 판단하는 IOU(Intersection over Union)를
측정해, 값이 큰 박스 들에 대해서 물체가 있을 확률이 가장 높은 박스만 남고 나머
지는 지워, 최종 경계 박스를 탐색한다. 탐색 된 경계 박스와 클래스는 미리 설정된
목표치(Ground Truth)에 대해 손실 함수를 평가하여, 경사 하강법의 방식으로 훈련
되며, 객체가 존재하지 않는 경계 박스에 대해서도 손실 함수를 계산하여 객체 탐색
에 대한 정확도를 높였다.
◦ 욜로는 그리드의 개수, 앵커 박스의 수 등의 다양한 하이퍼파라미터를 조정할 수 있
으며, 입력된 모델과 물체에 따라 하이퍼파라미터를 조절해 최적화된 모델을 만들

[그림 10] Intersection over Union
◦ 욜로 네트워크에서 성능 지표로는 IOU(Intersection over Union), 재현율
(Recall), 정밀도(Precision), mAP(mean Average Precision) 등이 쓰인다. IOU
는 두 경계 박스가 있을 때, 겹친 영역의 넓이 / 합친 영역의 넓이를 나타낸다. [그림
10]과 같이 두 경계 박스가 많은 영역이 겹칠수록 큰 값이 나오며, 최댓값은 1이다.
[그림 11] Box Detection에서의 검출 종류
◦ [그림 11]을 보면, 객체 탐색에서 검출된 객체는 positive, 검출되지 않은 객체는
negative로 나타낸다. 재현율은 실제로 검출돼야 하는 객체 중 옳게 예측된 객체
의 비율을 의미하며, 재현율 = TP / (TP + FN)으로 나타낼 수 있다. 정밀도는 모델
이 검출한 객체 중 실제로 옳은 객체인 것의 비율을 의미하며, 정밀도 = TP / (TP +
FP)로 나타낼 수 있다. 객체가 제대로 검출되었다(TP)는 것을 판단하는 기준은 보
통 두 정답 경계 박스와 예측된 경계 박스의 IOU가 일정 임계값(ex) 0.5)을 넘었다
면 TP로 판단한다. 재현율과 정밀도는 반비례 관계이기 때문에 성능 지표로 성능 변
화 전체를 확인해야 한다. 따라서 모델의 전반적인 성능을 평가하기 위해 PR 곡선
(Precision-Recall 곡선)이 사용된다. PR곡선은 객체의 존재 확률(Confidence)의
임계값을 0 ~ 1까지 조절하며 정밀도와 재현율을 [그림 12]와 같이 그래프로 나타낸
것이다. AP(Average Precision)는 모델 전반적인 성능뿐만 아니라 정량적인 평가를
계산하기 위해 사용한다. AP는 PR곡선의 아래쪽 면적을 계산한 값으로 [그림 12]의
빨간 선과 같이 보통 단조 감소 그래프로 변경하여 계산한다. mAP(mean Average

class YoloLayer(Layer):
    def __init__(self, anchors, max_grid, batch_size, warmup_batches, ignore_thresh,
                    grid_scale, obj_scale, noobj_scale, xywh_scale, class_scale,
                    **kwargs):
        # make the model settings persistent
        self.ignore_thresh  = ignore_thresh
        self.warmup_batches = warmup_batches
        self.anchors        = tf.constant(anchors, dtype=’float’, shape=[1,1,1,3,2])
        self.grid_scale     = grid_scale
        self.obj_scale      = obj_scale
        self.noobj_scale    = noobj_scale
        self.xywh_scale     = xywh_scale
        self.class_scale    = class_scale
        # make a persistent mesh grid
        max_grid_h, max_grid_w = max_grid
        cell_x = tf.to_float(tf.reshape(tf.tile(tf.range(max_grid_w), [max_grid_h]), (1, max_grid_h, max_grid_w, 1, 1)))
        cell_y = tf.transpose(cell_x, (0,2,1,3,4))
        self.cell_grid = tf.tile(tf.concat([cell_x,cell_y],-1), [batch_size, 1, 1, 3, 1])
        super(YoloLayer, self).__init__(**kwargs)
    def build(self, input_shape):
        super(YoloLayer, self).build(input_shape)  # Be sure to call this somewhere!
    def call(self, x):
        input_image, y_pred, y_true, true_boxes = x
        # adjust the shape of the y_predict [batch, grid_h, grid_w, 3, 4+1+nb_class]
        y_pred = tf.reshape(y_pred, tf.concat([tf.shape(y_pred)[:3], tf.constant([3, -1])], axis=0))

        object_mask     = tf.expand_dims(y_true[..., 4], 4)
        # the variable to keep track of number of batches processed
        batch_seen = tf.Variable(0.)
        # compute grid factor and net factor
        grid_h      = tf.shape(y_true)[1]
        grid_w      = tf.shape(y_true)[2]
        grid_factor = tf.reshape(tf.cast([grid_w, grid_h], tf.float32), [1,1,1,1,2])

def _conv_block(inp, convs, do_skip=True):
    x = inp
    count =0

    for conv in convs:
        if count == (len(convs) -2) and do_skip:
            skip_connection = x
        count +=1

        if conv[‘stride’] >1: x = ZeroPadding2D(((1,0),(1,0)))(x) # unlike tensorflow darknet prefer left and top paddings
        x = Conv2D(conv[‘filter’],
                   conv[‘kernel’],
                   strides=conv[‘stride’],
                   padding=’valid’if conv[‘stride’] >1 else ‘same’, # unlike tensorflow darknet prefer left and top paddings
                   name=’conv_’+str(conv[‘layer_idx’]),
                   use_bias=False if conv[‘bnorm’] else True)(x)
        if conv[‘bnorm’]: x = BatchNormalization(epsilon=0.001, name=’bnorm_’+str(conv[‘layer_idx’]))(x)
        if conv[‘leaky’]: x = LeakyReLU(alpha=0.1, name=’leaky_’+str(conv[‘layer_idx’]))(x)

    return add([skip_connection, x]) if do_skip else x
