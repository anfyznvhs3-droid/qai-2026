# 경진대회용 우선 후보 3축

기준: 2026 과제 공개 전 사전 선별. 공식 과제·평가지표가 공개되면 다시 검증한다.

## 1순위 후보군

| 축 | 데이터셋 | 선택 이유 | 먼저 검증할 것 |
|---|---|---|---|
| 품질/이상탐지 | ID 21 — 품질 이상탐지·진단(도금욕) | 품질 예측과 불량 원인 설명을 현장 KPI로 연결하기 좋음 | 불량 라벨 시점, LOT·설비 분할, 사후변수 포함 여부 |
| 예지보전 | ID 18 — 회전기계 고장유형 | 정상/고장 진단과 예방정비 시나리오가 분명함 | 시간·센서 윈도우 중첩, 정상/고장 불균형, 조기경보 리드타임 |
| 공정 최적화 | ID 19 — 공정운영 최적화 | 공정 조건 조정과 비용·품질 개선을 함께 설명하기 좋음 | 목표변수의 계산 시점, 공정조건과 결과의 인과 방향, 운영 제약 |

## 과제 유형별 백업 후보

- 품질/이상탐지: ID 20 전해탈지, ID 25 크로메이트, ID 10 살균기
- 예지보전: ID 43 열처리, ID 54 주조 설비, ID 56 사출성형
- 최적화: ID 28 생산공정, ID 27 자원, ID 61 열처리

## 선택 규칙

1. 과제의 목표변수와 위 3축 중 하나가 직접 일치하는 후보만 남긴다.
2. 라벨 생성 시점과 예측 시점이 분리되지 않으면 탈락시킨다.
3. 시간·LOT·설비 단위의 누수 없는 검증 분할이 가능해야 한다.
4. 모델 출력이 알람·점검·조건 수정 중 하나의 행동으로 연결되어야 한다.
5. 검증 가능한 KPI와 기준선이 없는 후보는 성능이 좋아도 보류한다.

## 현재 판단

지금은 rawdata 전체를 추가 분석하지 않는다. 위 3개 후보의 가이드북과 상세 텍스트에서 데이터 카드, 라벨 정의, 누수 점검표를 먼저 만들고, 과제 공개 후 실제 목표와 매칭되는 한 개만 선택한다.

`dataset-selection-matrix.csv`는 50개 상세 페이지 전체의 기계 판독용 표이며, 점수는 공식 평가점수가 아닌 사전 선별용 휴리스틱이다.
