# KAMP 포털 과거 공지에서 확인한 DATA 흐름

기준일: 2026-09-11  
출처: 프로젝트에 보존된 KAMP 공개 페이지와 공식 공지 원문

## 포털 공지 목록에서 확인한 회차별 구조

KAMP 경진대회 공지 목록은 다음 자료를 별도 게시했다.

| 회차 | 공고 | 과제/문제 공개 | 발표평가 대상 공개 |
|---:|---|---|---|
| 2026 제6회 | 있음 | 공개 전/확인 필요 | - |
| 2025 제5회 | 있음 | 있음 | 있음 |
| 2024 제4회 | 있음 | 있음 | 있음 |
| 2023 제3회 | 있음 | 문제발표 있음 | 있음 |
| 2022 제2회 | 공고·과제 자료 확인 | 과제 공개 자료 확인 | - |

이 구조는 2026년에도 다음 순서로 움직일 가능성을 높인다.

1. 공고에서 참가·제출 규칙 확인
2. 과제 공개에서 실제 데이터셋/목표 확인
3. 제한된 기간에 분석
4. 보고서·발표·코드 제출
5. 서면 상위 8팀 → 발표평가

## 2022년 과제 공개: 실제 DATA와 타깃

KAMP 과제 공개 원문에서 확인된 데이터는 다음과 같다.

- 과제: 식품가공 기업의 작업환경 개선 및 생산성 향상
- 제조AI데이터셋: **용해탱크 제조AI데이터셋**
- 파일명: `경진대회 용해탱크 데이터셋.csv`
- 분석 축:
  - 용해탱크 장비이상 조기탐지
  - 용해물 품질공정 제어
  - 용해물 품질이상 탐지/진단
  - 원재료 폐기량·설비가동률 중심 자원 최적화

제출물은 보고서 PDF, 발표자료 PDF/PPT, Python 기반 `.ipynb`였다. 서면평가는 성능 30점과 문제 이해·데이터셋 이해·문제 정의·독창성·분석 타당성·결과해석·결과물 작성 각 10점의 구조였고, 발표평가는 발표능력 10점, 문제해결 독창성 20점, 분석 과정 20점, 적용 가능성 20점, 확장성 30점이었다.

**전략적 의미:** 한 개의 제조 데이터셋도 장비이상·품질·최적화·자원이라는 여러 운영 문제로 재해석할 수 있었다. 2026년에도 데이터셋을 보는 즉시 최소 3개의 현장 문제 가설을 병렬로 만든다.

근거: [KAMP 2022 과제 공개 원문](https://www.kamp-ai.kr/contestNoticeDetail?CPT_NOTICE_SEQ=10), [KAMP 공지 목록](https://www.kamp-ai.kr/contestNoticeList)

## 2025년 과제 공개: 50종에서 3종으로 축소

2025년 과제 공개 원문에는 팀별 선택지가 아래 3종으로 기재되어 있다.

1. 열처리 공정최적화 AI 데이터셋
2. 소성가공 품질보증 AI 데이터셋
3. 사출성형 공급망 최적화 AI 데이터셋

제조기업의 생산성 향상·작업환경 개선을 목표로 하며, 보고서 PDF, 발표자료 PDF/PPT, 코드 또는 분석 화면 캡처, 설문 증빙을 제출하게 했다.

세부 배점은 [past-contest-data-2025-addendum.md](past-contest-data-2025-addendum.md)에 전사했다.

근거: [KAMP 2025 과제 공개 원문](https://www.kamp-ai.kr/contestNoticeDetail?CPT_NOTICE_SEQ=21)

## 2023·2024 자료의 현재 확인 수준

KAMP 포털 공지 목록에는 2023년 문제발표와 2024년 과제공개가 존재하고 첨부파일 수도 확인되지만, 현재 공개 본문 수집에서는 해당 상세 본문이 빈 껍데기로 반환되어 첨부 파일 내용까지는 확인하지 못했다. 이 항목은 `review_needed`다.

대신 주최기관·수상팀 공개 자료로 다음을 교차 확인했다.

- 2023: 열처리 품질보증 데이터셋 약 6,100만 데이터, 대상은 XAI 기반 실시간 설비 이상탐지.
- 2024: 50종 중 1종을 활용하는 공고, 최우수상은 멀티태스크 고장 예측·분석·역설계 기반 최적 후보 탐색.

근거: [KAIST 2023 결과 발표](https://kaist.ac.kr/news/html/news/?GotoPage=1&list_e_date=&list_s_date=&mng_no=33190&mode=V&skey=keyword&sval=%EB%B9%85), [2024 공고 게시본](https://mnucc.mokpo.ac.kr/bbs/ce/614/268023/artclView.do), [2024 수상팀 설명](https://hai.snu.ac.kr/bbs/board.php?bo_table=sub6_1&page=3&wr_id=295)

## 2026년 준비 방식

과제 공개 전에는 다음만 준비한다.

- 50종 후보의 가이드북·상세 페이지·데이터 형태 이해
- 품질/예지보전/최적화별 문제 정의 템플릿
- 누수 없는 LOT·세션·시간 분할 코드
- 보고서·발표·코드 재현 템플릿

과제 공개 후 30분 안에 수행할 일은 다음과 같다.

1. 실제 선택 데이터셋과 첨부 파일 다운로드
2. 타깃·예측 시점·평가 단위 확인
3. 3개 문제 가설 작성
4. 데이터 사전·조인·결측·불균형 요약
5. 과거 평가표에 맞춰 주력 문제 1개 확정
