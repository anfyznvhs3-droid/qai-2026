# 과거 K-인공지능 제조데이터 경진대회 DATA 조사

작성일: 2026-09-11  
범위: 제1회~제5회 공개 공고·주최기관 발표·수상팀 공개 자료  
목적: 2026년 과제 공개 전, 어떤 데이터 문제 정의와 결과물이 실제 수상으로 연결됐는지 파악한다.

## 결론

과거 수상작은 단순히 높은 정확도의 모델을 제출한 것이 아니라 다음 흐름을 갖췄다.

> 제조 현장 문제 → 예측 가능한 의사결정 시점 → 조기경보/원인설명 → 운영 조치 → 다른 공정으로의 확장성

따라서 우리 전략은 모델을 먼저 고르는 방식이 아니라, 공개된 데이터에서 **실제 조치 가능한 타깃과 시간축을 먼저 고정한 뒤 모델을 선택하는 방식**으로 간다.

#### 2021년 제1회

KAIST 공식 발표는 사출성형 데이터셋이 47개 변수와 약 4,200만 개 데이터로 구성됐다고 설명한다. 대상팀은 사출물 품질 이상진단과 공정 최적화를 지원하는 모델을 개발했고, 심사에서는 문제 이해·정의, 독창성, 결과 해석, 성능 정확도뿐 아니라 최종 발표에서 창의성·현장 적용성·파급효과를 보았다.

근거: [KAIST 제1회 공식 발표](https://kaist.ac.kr/news/html/news/?GotoPage=1&list_e_date=&list_s_date=&mng_no=18070&mode=V&skey=keyword&sval=Cube+J)

## 과거 DATA에서 추출한 승리 규칙

### 1. 데이터셋 자체보다 문제 재정의가 승부처

동일 제조 데이터도 “분류 정확도”로 끝내지 않고 다음 중 하나로 재정의한 작품이 강했다.

- 몇 분/몇 사이클 전에 이상을 알릴 것인가
- 어떤 공정변수가 불량을 유발했는가
- 어떤 조건 범위로 조정하면 품질이 좋아지는가
- 동일 모델을 다른 공정·설비에 어떻게 확장할 것인가

### 2. 라벨이 희소하거나 불균형하면 오히려 기회

2022년 대상은 준지도학습과 불량 발생시점 예측을 결합했다. 2024년 공개 사례도 Pass/Fail 불균형에서 전체 accuracy가 아니라 Fail F1을 중심으로 평가했다. 우리도 정상/불량 비율, 라벨 생성 주기, 미라벨 구간을 처음부터 전략 자산으로 취급한다.

### 3. 설명은 장식이 아니라 심사 산출물

XAI, 변수 기여도, 임계값, 공정 조치, 작업자 화면까지 연결해야 한다. 단순 SHAP 그림 하나보다 “이 경보가 발생하면 pH를 확인하고, 전류 변동을 점검하며, 다음 LOT를 보류한다”와 같은 행동 규칙이 필요하다.

### 4. 도메인 지식을 넣을수록 차별화 가능

2025년 대상은 물리식 기반 시계열 회귀를 사용했다. 우리 후보에서도 무리한 복잡한 딥러닝보다 공정 제약, 물리적으로 가능한 범위, 시간 순서, 원인-결과 방향을 모델과 평가에 넣는 편이 유리하다.

### 5. 최종 산출물은 모델이 아니라 현장 패키지

과거 공식 발표에서 반복된 평가 언어는 현장 적용성, 파급효과, 확장성, 기술적 완성도다. 따라서 제출물에는 최소한 다음이 있어야 한다.

- 문제 정의와 예측 시점
- 누수 없는 분할과 기준선
- 성능 지표와 불균형 대응
- 오류 사례와 원인 가설
- 변수 기여도/설명
- 현장 경보 또는 공정 조정 규칙
- 다른 LOT·기간·설비로 확장할 수 있는 구조

## 우리 후보에 적용한 우선순위 변경

### ID 21 — 품질 이상탐지·진단: 주력 유지

2023년의 XAI 실시간 이상탐지 패턴과 가장 직접적으로 맞는다. Error Lot을 단순 분류하는 대신 **LOT 조기경보 + 센서 원인 + 다음 조치**로 설계한다. 주 지표도 row accuracy보다 LOT 단위 위험 LOT recall/PR-AUC와 경보 리드타임으로 잡는다.

### ID 19 — 공정운영 최적화: 주력에 준하는 스토리 후보

2021년의 품질+공정 최적화, 2024년의 최적 후보 탐색, 2025년의 도메인 기반 모델 흐름과 맞는다. Process Rate 회귀만 제출하지 말고, 관측 범위와 공정 제약 안에서 pH·Temp 조정안을 추천하는 형태로 확장한다.

### ID 18 — 모델링 기준선, 단독 주력은 조건부

고장 분류 자체는 명확하지만, 순수 4-class 정확도만으로는 과거 수상 패턴의 현장 차별화가 약하다. 주력으로 올리려면 세션 간 일반화, 조기 고장경보, 센서 위치 변화, 고장 유형별 점검 조치 중 최소 하나를 추가해야 한다.

## 데이터 공개 직후 먼저 볼 과거 패턴 검증 항목

1. 과제 타깃이 완료 후 라벨인지, 공정 중 예측 가능한 라벨인지 확인한다.
2. row/LOT/session 중 공식 의사결정 단위를 확정한다.
3. 정상/불량 클래스 비율과 라벨 생성 주기를 계산한다.
4. 수상 패턴에 맞춰 조기경보·원인설명·조건추천 중 어떤 축이 가장 자연스러운지 선택한다.
5. 랜덤 분할 점수는 참고만 하고 LOT·세션·시간 홀드아웃을 기본 성능으로 삼는다.
6. 마지막에는 모델 성능이 아니라 현장 KPI 변화와 확장 시나리오를 발표 구조의 중심에 둔다.

## 조사 한계

- KAMP 포털 자체의 과거 공지 상세 페이지는 현재 공개 검색 색인이 제한적이어서, 공식 KAIST 발표와 공고 게시본·수상팀 공개 저장소를 교차 사용했다.
- 2024 참가 저장소의 수치·모델은 개인 공개 기록이므로 전체 수상작의 공식 평가 결과로 일반화하지 않는다.
- 2026년 과제·평가지표·데이터 선택 방식은 공식 공고가 확인될 때까지 `review_needed`다.
